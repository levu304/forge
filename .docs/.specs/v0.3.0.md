# Forge v0.3.0 Technical Specification

> **Organization — The Layered Canvas**  
> *Layer system, block definitions/insertions, property inheritance, advanced draw commands, and grip editing atop the v0.2.0 editing foundation.*  
> **Revision Date:** 2026-05-28 Rev 15

---

## 1. Scope & Objectives

### 1.1 In Scope
- **Layer system** — create, rename, delete, reorder; per-layer color, linetype, linewidth, visibility, lock, freeze
- **Entity-to-layer assignment** with `ByLayer` / `ByBlock` / explicit property inheritance
- **Block system** — block definitions (blueprints), block inserts (transformed instances), block definitions containing Line/Circle/Arc/Polyline entities (no nested blocks — deferred to v0.3.1), explode
- **Block editor** — in-place editing mode for block definitions
- **Property palette** — live read/write editing of entity and layer attributes via `egui`
- **Match properties** — copy attributes between entities
- **Advanced draw commands** — `RECTANGLE`, `POLYGON`, `ELLIPSE`, `SPLINE`
- **Grip editing** — interactive drag handles on selected entities for direct manipulation
- **Multi-select modifier keys** — `Ctrl+click` add/remove from selection (deferred from v0.2.0)

### 1.2 Out of Scope
- Dimensioning (v0.4.0)
- Hatch & fill patterns (v0.4.0)
- Text & annotations (v0.4.0)
- File I/O (v0.5.0)
- Constraint solving (v0.7.0)
- Parametric expressions (v0.7.0)
- Nested blocks (block-within-block) — deferred to v0.3.1

## 5. Layer System

### 5.1 Layer Model

A **Layer** is a named collection of display properties. Every entity belongs to exactly one layer. The `LayerTable` is a resource (singleton) that owns all layers.

```rust
// src/layer/layer.rs
use crate::util::Color;

/// Unique layer identifier. 0 is reserved for the default layer.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct LayerId(pub u32);

impl LayerId {
    pub const DEFAULT: LayerId = LayerId(0);
}

#[derive(Debug, Clone)]
pub struct Layer {
    pub id: LayerId,
    pub name: String,
    pub color: Color,           // Default color for entities on this layer
    pub linetype: Linetype,   // Solid, Dashed, DotDash, etc.
    pub linewidth: f32,         // Default line width
    pub visible: bool,          // Rendered?
    pub locked: bool,           // Selectable/modifiable?
    pub frozen: bool,           // Completely ignored (not rendered, not selectable)
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Linetype {
    #[default]
    Solid,
    Dashed,
    Dot,
    DotDash,
    Border,
    Center,
}
```

> **v0.3.0 Limitation:** `Linetype::Border` and `Linetype::Center` are defined as valid values but their shader rendering is deferred to v0.3.1. In v0.3.0, setting either falls back to `Linetype::Solid`. The PropertyPalette and LayerPanel should display these with a "(coming soon)" label or disable them.

```rust
// src/layer/table.rs
use std::collections::HashMap;

pub struct LayerTable {
    pub layers: HashMap<LayerId, Layer>,
    pub name_to_id: HashMap<String, LayerId>,
    pub next_id: u32,
    pub active_layer: LayerId,
}

impl LayerTable {
    pub fn new() -> Self {
        let mut table = Self {
            layers: HashMap::new(),
            name_to_id: HashMap::new(),
            next_id: 0,
            active_layer: LayerId::DEFAULT,
        };
        // Create default layer
        table.insert(Layer {
            id: LayerId::DEFAULT,
            name: "0".to_string(),
            color: Color::WHITE,
            linetype: Linetype::Solid,
            linewidth: 1.0,
            visible: true,
            locked: false,
            frozen: false,
        });
        table
    }

    pub fn insert(&mut self, layer: Layer) -> Result<LayerId, LayerError> {
        if self.name_to_id.contains_key(&layer.name) {
            return Err(LayerError::NameExists);
        }
        let id = LayerId(self.next_id);
        self.next_id += 1;
        self.name_to_id.insert(layer.name.clone(), id);
        self.layers.insert(id, Layer { id, ..layer });
        Ok(id)
    }

    pub fn delete(&mut self, id: LayerId, number_of_references: usize) -> Result<(), LayerError> {
        if id == LayerId::DEFAULT {
            return Err(LayerError::CannotDeleteDefault);
        }
        if number_of_references > 0 {
            return Err(LayerError::LayerInUse { count: number_of_references });
        }
        if let Some(layer) = self.layers.remove(&id) {
            self.name_to_id.remove(&layer.name);
        }
        Ok(())
    }

    pub fn rename(&mut self, id: LayerId, new_name: String) -> Result<(), LayerError> {
        if self.name_to_id.contains_key(&new_name) {
            return Err(LayerError::NameExists);
        }
        let layer = self.layers.get_mut(&id).ok_or(LayerError::NotFound)?;
        self.name_to_id.remove(&layer.name);
        layer.name = new_name.clone();
        self.name_to_id.insert(new_name, id);
        Ok(())
    }

    pub fn get(&self, id: LayerId) -> Option<&Layer> {
        self.layers.get(&id)
    }

    pub fn get_by_name(&self, name: &str) -> Option<&Layer> {
        self.name_to_id.get(name).and_then(|id| self.layers.get(id))
    }
}

#[derive(Debug, thiserror::Error)]
pub enum LayerError {
    #[error("Cannot delete the default layer")]
    CannotDeleteDefault,
    #[error("Layer name already exists")]
    NameExists,
    #[error("Layer not found")]
    NotFound,
    #[error("Layer is in use by {count} entities")]
    LayerInUse { count: usize },
}
```

> **Note:** Layer ordering is tracked via insertion order in the `layers: HashMap<LayerId, Layer>` structure. For v0.3.0, layers are iterated in arbitrary order in the panel. An explicit `order: u32` field will be added in v0.3.1 for drag-to-reorder support.

```rust
/// Thin owning wrapper around LayerTable.
pub struct LayerManager {
    pub table: LayerTable,
}
impl LayerManager {
    pub fn new() -> Self { Self { table: LayerTable::new() } }

    /// Delete a layer, checking for entity references first.
    /// Returns `Err(LayerInUse)` if any entities still reference this layer.
    pub fn delete_layer(&mut self, world: &hecs::World, id: LayerId) -> Result<(), LayerError> {
        let count = world.query::<&LayerRef>().iter()
            .filter(|(_, lr)| lr.0 == id)
            .count();
        self.table.delete(id, count)
    }
}
```

> **Implementation Note — Layer Deletion Entity Migration:** When layer deletion fails with `LayerInUse`, the UI should offer to batch-move affected entities to another layer (e.g., via the active layer). The property palette's multi-select layer change operation can be used for this.

### 5.3 Property Inheritance

```rust
// src/ecs/components.rs
/// How an entity resolves its display properties.
#[derive(Debug, Clone, Copy, Component, Default)]
pub struct PropertySource {
    pub color: PropertyValue<Color>,
    pub linewidth: PropertyValue<f32>,
    pub linetype: PropertyValue<Linetype>,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum PropertyValue<T> {
    ByLayer,      // Use layer's value (default — see manual Default impl)
    ByBlock,      // Use block insert's value (for entities inside blocks)
    Explicit(T),  // Entity-specific override
}

// Manual Default impl: always returns ByLayer regardless of T.
// Note: do NOT derive Default on the enum — the derive breaks for types that
// don't implement Default (e.g., non-Default generics). The manual impl below
// is the canonical default.
impl<T> Default for PropertyValue<T> {
    fn default() -> Self {
        PropertyValue::ByLayer
    }
}
```

> **Note:** `PropertyValue<T>` now has a manual `Default` impl that always returns `ByLayer`, regardless of `T`. `PropertySource` still derives `Default` — all three fields default to `ByLayer`. This is correct for entities created directly in the main world (not inside blocks).

### 5.4 Property Resolver

```rust
// src/property/resolver.rs
use hecs::World;

pub struct PropertyResolver;

impl PropertyResolver {
    /// Resolve the effective color of an entity for rendering.
    /// `parent_block_ref` provides the containing BlockRef entity context
    /// for resolving `ByBlock` property values (single-level hierarchy).
    pub fn resolve_color(
        world: &World,
        layer_table: &LayerTable,
        entity: hecs::Entity,
        parent_block_ref: Option<hecs::Entity>,  // NEW
    ) -> Color {
        if let Ok(Some(source)) = world.query_one::<&PropertySource>(entity).get() {
            match source.color {
                PropertyValue::Explicit(c) => c,
                PropertyValue::ByLayer => {
                    if let Ok(Some(layer_ref)) = world.query_one::<&LayerRef>(entity).get() {
                        layer_table.get(layer_ref.0)
                            .map(|l| l.color)
                            .unwrap_or(Color::WHITE)
                    } else {
                        Color::WHITE
                    }
                }
                PropertyValue::ByBlock => {
                    if let Some(parent_block) = parent_block_ref {
                        Self::resolve_color(world, layer_table, parent_block, None)
                    } else {
                        // No parent block — fall through to ByLayer
                        let layer_ref = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
                        if let Some(ref lr) = layer_ref {
                            layer_table.get(lr.0).map(|l| l.color).unwrap_or(Color::WHITE)
                        } else {
                            Color::WHITE
                        }
                    }
                }
            }
        } else {
            let lr = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
            lr.and_then(|r| layer_table.get(r.0).map(|l| l.color)).unwrap_or(Color::WHITE)
        }
    }

    pub fn resolve_linewidth(
        world: &World,
        layer_table: &LayerTable,
        entity: hecs::Entity,
        parent_block_ref: Option<hecs::Entity>,
    ) -> f32 {
        if let Ok(Some(source)) = world.query_one::<&PropertySource>(entity).get() {
            match source.linewidth {
                PropertyValue::Explicit(w) => w,
                PropertyValue::ByLayer => {
                    if let Ok(Some(layer_ref)) = world.query_one::<&LayerRef>(entity).get() {
                        layer_table.get(layer_ref.0).map(|l| l.linewidth).unwrap_or(1.0)
                    } else { 1.0 }
                }
                PropertyValue::ByBlock => {
                    if let Some(parent) = parent_block_ref {
                        Self::resolve_linewidth(world, layer_table, parent, None)
                    } else {
                        let layer_ref = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
                        if let Some(ref lr) = layer_ref {
                            layer_table.get(lr.0).map(|l| l.linewidth).unwrap_or(1.0)
                        } else {
                            1.0
                        }
                    }
                }
            }
        } else {
            let lr = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
            lr.and_then(|r| layer_table.get(r.0).map(|l| l.linewidth)).unwrap_or(1.0)
        }
    }

    pub fn resolve_linetype(
        world: &World,
        layer_table: &LayerTable,
        entity: hecs::Entity,
        parent_block_ref: Option<hecs::Entity>,
    ) -> Linetype {
        if let Ok(Some(source)) = world.query_one::<&PropertySource>(entity).get() {
            match source.linetype {
                PropertyValue::Explicit(lt) => lt,
                PropertyValue::ByLayer => {
                    if let Ok(Some(layer_ref)) = world.query_one::<&LayerRef>(entity).get() {
                        layer_table.get(layer_ref.0).map(|l| l.linetype).unwrap_or(Linetype::Solid)
                    } else { Linetype::Solid }
                }
                PropertyValue::ByBlock => {
                    if let Some(parent) = parent_block_ref {
                        Self::resolve_linetype(world, layer_table, parent, None)
                    } else {
                        let layer_ref = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
                        if let Some(ref lr) = layer_ref {
                            layer_table.get(lr.0).map(|l| l.linetype).unwrap_or(Linetype::Solid)
                        } else {
                            Linetype::Solid
                        }
                    }
                }
            }
        } else {
            let lr = world.query_one::<&LayerRef>(entity).get().ok().flatten().copied();
            lr.and_then(|r| layer_table.get(r.0).map(|l| l.linetype)).unwrap_or(Linetype::Solid)
        }
    }

    /// Direct resolution from PropertySource field values (for BlockEntity entities
    /// stored in Vec<BlockEntity>, not in the ECS World).
    pub fn resolve_color_direct(
        source: &PropertySource,
        layer_ref: &LayerRef,
        layer_table: &LayerTable,
        parent_block_ref: Option<&BlockRef>,
    ) -> Color {
        match source.color {
            PropertyValue::Explicit(c) => c,
            PropertyValue::ByLayer | PropertyValue::ByBlock => {
                // v0.3.0: ByBlock simplified to fall through to layer default.
                // Full parent-block resolution deferred to v0.3.1.
                layer_table.get(layer_ref.0)
                    .map(|l| l.color)
                    .unwrap_or(Color::WHITE)
            }
        }
    }

    /// Direct linewidth resolution from field values.
    pub fn resolve_linewidth_direct(
        source: &PropertySource,
        layer_ref: &LayerRef,
        layer_table: &LayerTable,
        parent_block_ref: Option<&BlockRef>,
    ) -> f32 {
        match source.linewidth {
            PropertyValue::Explicit(w) => w,
            PropertyValue::ByLayer | PropertyValue::ByBlock => {
                // v0.3.0: ByBlock simplified to fall through to layer default.
                // Full parent-block resolution deferred to v0.3.1.
                layer_table.get(layer_ref.0).map(|l| l.linewidth).unwrap_or(1.0)
            }
        }
    }

    /// Direct linetype resolution from field values.
    pub fn resolve_linetype_direct(
        source: &PropertySource,
        layer_ref: &LayerRef,
        layer_table: &LayerTable,
        parent_block_ref: Option<&BlockRef>,
    ) -> Linetype {
        match source.linetype {
            PropertyValue::Explicit(lt) => lt,
            PropertyValue::ByLayer | PropertyValue::ByBlock => {

        }
    }
}
```

> - Cleared when LayerTable modifies a layer's default color/linetype/linewidth
> - Lazily rebuilt by PropertyResolver on first per-frame access

> **Known Limitation — v0.3.0:** `ByBlock` property resolution for entities stored inside block definitions (i.e., `BlockEntity` variants) is supported only via the explicit `parent_block_ref` parameter. When this parameter is `None` (the common case outside block editor context), `ByBlock` falls through to `ByLayer`. Full multi-level `ByBlock` resolution across block definition nesting is deferred to v0.3.1. Entities stored directly in the ECS (main world entities) always resolve correctly when a `BlockRef` parent is provided.

> **EntityRenderer Changes for Layer Culling (v0.3.0):**
> 1. `EntityRenderer::render()` gains a `layer_table: &LayerTable` parameter.
> 2. Vertex collection queries change from `query::<(&LineData, &Renderable)>()` to `query::<(&LineData, &Renderable, &LayerRef)>()`.
> 3. Before writing vertices for an entity, check: `layer_table.layers.get(&layer_ref.0).map(|l| l.visible && !l.frozen).unwrap_or(true)`. Skip invisible/frozen entities.
> 4. Selection highlighting still applies to invisible entities (they can be selected but not modified).

## 6. Block System

### 6.1 Block Definition

A **Block Definition** is a named, reusable collection of entities. It has a base point (insertion origin) and its own local coordinate system.

```rust
// src/block/definition.rs
use hecs::World;

/// A block definition (blueprint). Stored in BlockTable, not the main World.
#[derive(Debug, Clone)]
pub struct BlockDef {
    pub name: String,
    pub base_point: Point2D,
    /// Local entity storage for the block's geometry.
    /// Each entry is (Position, LineData/CircleData/etc., PropertySource, LayerRef)
    pub entities: Vec<BlockEntity>,
    pub bounds: BoundingBox2D,
}

/// Serialized entity data within a block definition.
/// We use a custom enum instead of hecs::World to avoid nested ECS complexity.
#[derive(Debug, Clone)]
pub enum BlockEntity {
    Line(Point2D, Point2D, PropertySource, LayerRef),
    Circle(Point2D, f64, PropertySource, LayerRef),
    Arc(Point2D, f64, f64, f64, PropertySource, LayerRef),
    Polyline(Vec<Point2D>, bool, PropertySource, LayerRef),
}

impl BlockEntity {
    /// Compute the world-space bounding box of this block entity.
    /// Used by BlockDef::compute_bounds() to determine block extents.
    pub fn bounding_box(&self) -> BoundingBox2D {
        match self {
            BlockEntity::Line(start, end, ..) => {
                BoundingBox2D::from_points(&[*start, *end])
            }
            BlockEntity::Circle(center, radius, ..) => {
                BoundingBox2D {
                    min: Point2D::new(center.x - radius, center.y - radius),
                    max: Point2D::new(center.x + radius, center.y + radius),
                }
            }
            BlockEntity::Arc(center, radius, ..) => {
                // Conservative: full circle bound (arc endpoints fall within)
                BoundingBox2D {
                    min: Point2D::new(center.x - radius, center.y - radius),
                    max: Point2D::new(center.x + radius, center.y + radius),
                }
            }
            BlockEntity::Polyline(vertices, ..) => BoundingBox2D::from_points(vertices),
        }
    }
}

impl BlockDef {
    pub fn compute_bounds(&mut self) {
        // Compute union of all entity bounds
        self.bounds = self.entities.iter()
            .map(|e| e.bounding_box())
            .fold(BoundingBox2D::empty(), |a, b| a.union(&b));
    }
}
```

> **Spline Storage:** Spline entities (`CubicBezier`) are approximated as polylines when stored inside block definitions. For v0.3.0, a `Spline` variant is not added to `BlockEntity`; splines are converted to `BlockEntity::Polyline` with 64 segments at block definition time. This avoids expanding the `BlockEntity` enum for a v0.3.0 feature that is rarely used inside blocks.

### 6.2 Block Insert

A **Block Insert** is an entity in the main World that references a BlockDef and carries a transform.

```rust
// src/geometry/transform.rs
use crate::geometry::Point2D;
use crate::geometry::BoundingBox2D;

/// A 2D affine transformation: scale, rotate, translate (applied in that order).
#[derive(Debug, Clone, Copy)]
pub struct Transform2D {
    pub position: Point2D,       // Translation (insertion point offset)
    pub scale: Point2D,          // Uniform or non-uniform scale (x, y)
    pub rotation_degrees: f64,   // Rotation in degrees (matches ArcData convention)
}

impl Transform2D {
    /// Identity transform (no translation, scale=1, rotation=0).
    pub const IDENTITY: Transform2D = Transform2D {
        position: Point2D::new(0.0, 0.0),
        scale: Point2D::new(1.0, 1.0),
        rotation_degrees: 0.0,
    };

    /// Apply this transform to a point: translate, rotate, scale
    /// Composition order: scale → rotate → translate
    pub fn apply_to_point(&self, p: Point2D) -> Point2D {
        // Scale
        let sx = p.x * self.scale.x;
        let sy = p.y * self.scale.y;
        // Rotate
        let rad = self.rotation_degrees.to_radians();
        let cos_a = rad.cos();
        let sin_a = rad.sin();
        let rx = sx * cos_a - sy * sin_a;
        let ry = sx * sin_a + sy * cos_a;
        // Translate
        Point2D::new(rx + self.position.x, ry + self.position.y)
    }

    /// Compute the bounding box of a point set transformed by this transform.
    pub fn apply_to_bounds(&self, bounds: &BoundingBox2D) -> BoundingBox2D {
        let corners = [
            self.apply_to_point(Point2D::new(bounds.min.x, bounds.min.y)),
            self.apply_to_point(Point2D::new(bounds.max.x, bounds.min.y)),
            self.apply_to_point(Point2D::new(bounds.min.x, bounds.max.y)),
            self.apply_to_point(Point2D::new(bounds.max.x, bounds.max.y)),
        ];
        BoundingBox2D::from_points(&corners)
    }
}
```

```rust
impl BoundingBox2D {
    /// Create an infinitely-small bounding box (suitable for accumulation).
    pub fn empty() -> Self {
        Self {
            min: Point2D::new(f64::MAX, f64::MAX),
            max: Point2D::new(f64::MIN, f64::MIN),
        }
    }

    /// Compute the tight axis-aligned bounding box of a slice of points.
    pub fn from_points(points: &[Point2D]) -> Self {
        let mut bb = Self::empty();
        for p in points {
            bb.min.x = bb.min.x.min(p.x);
            bb.min.y = bb.min.y.min(p.y);
            bb.max.x = bb.max.x.max(p.x);
            bb.max.y = bb.max.y.max(p.y);
        }
        bb
    }
}
```

#### 6.2.1 BlockTable

```rust
// src/block/definition.rs
use std::collections::HashMap;

pub struct BlockTable {
    pub definitions: HashMap<BlockId, BlockDef>,
    pub name_to_id: HashMap<String, BlockId>,
    pub next_id: u32,
}

impl BlockTable {
    pub fn new() -> Self {
        Self { definitions: HashMap::new(), name_to_id: HashMap::new(), next_id: 0 }
    }

    pub fn insert(&mut self, def: BlockDef) -> Result<BlockId, BlockError> {
        if self.name_to_id.contains_key(&def.name) {
            return Err(BlockError::NameExists);
        }
        let id = BlockId(self.next_id);
        self.next_id += 1;
        self.name_to_id.insert(def.name.clone(), id);
        self.definitions.insert(id, def);
        Ok(id)
    }

    pub fn get(&self, id: BlockId) -> Option<&BlockDef> {
        self.definitions.get(&id)
    }
}

#[derive(Debug, thiserror::Error)]
pub enum BlockError {
    #[error("Block name already exists")]
    NameExists,
    #[error("Block not found")]
    BlockNotFound,
}

/// Thin owning wrapper around BlockTable.
pub struct BlockManager {
    pub table: BlockTable,
}
impl BlockManager {
    pub fn new() -> Self { Self { table: BlockTable::new() } }
}
```

> **Note (Modify Command Compatibility):** `BlockRef` entities carry a `Position` component that mirrors `transform.position` for compatibility with v0.2.0 modify commands. BlockRef entities also carry `PropertySource` and `LayerRef` components so that property resolution (ByBlock/ByLayer) and layer visibility culling work correctly on block instances. When spawning a BlockRef entity:
> ```rust
> world.spawn((
>     Position(transform.position),
>     BlockRef { definition, transform },
>     PropertySource::default(),
>     LayerRef::default(),
>     Renderable,
> ));
> ```
>
> Modify commands update BOTH `Position` and `BlockRef.transform.position`:
> ```rust
> if let Ok(Some(mut pos)) = world.query_one::<&mut Position>(entity).get() {
>     pos.0.x += dx; pos.0.y += dy;
> }
> if let Ok(Some(mut block_ref)) = world.query_one::<&mut BlockRef>(entity).get() {
>     block_ref.transform.position.x += dx;
>     block_ref.transform.position.y += dy;
> }
> ```
>
> **Note:** ROTATE, SCALE, and MIRROR on BlockRef entities update the `Position` component but do not update
> `BlockRef.transform.rotation_degrees` or `scale` fields, which may cause visual drift between the entity
> position and the block's rendered geometry. For v0.3.0, block inserts should be transformed via the block
> editor or property palette rather than generic modify commands. Full BlockRef transform support for all
> modify commands is deferred to v0.3.1.

### 6.3 Block Rendering

Block inserts are rendered by **expanding** the BlockDef entities into the main EntityRenderer's per-type vertex buffers. The `BlockRenderer` does NOT issue independent draw calls — it shares pipeline state with the `EntityRenderer` to maintain batching and selection highlighting.

```rust
// src/render/block_renderer.rs
pub struct BlockRenderer;

impl BlockRenderer {
    /// Expand block insert entities into the provided per-type vertex buffers.
    /// Called AFTER main entity vertex collection but BEFORE the render pass draw call.
    /// `block_table` provides the definition geometry; `selection` provides
    /// is_selected flags for per-instance selection highlighting.
    pub fn expand_into_vertex_buffers(
        world: &hecs::World,
        layer_table: &LayerTable,
        block_table: &BlockTable,
        selection: &SelectionManager,
        zoom: f64,
        line_out: &mut Vec<EntityVertex>,
        circle_out: &mut Vec<EntityVertex>,
        arc_out: &mut Vec<EntityVertex>,
        polyline_out: &mut Vec<EntityVertex>,
    ) {
        let mut query = world.query::<(&BlockRef, &LayerRef, &Renderable)>();
        for (entity, (block_ref, layer_ref, _)) in query.iter() {
            // Layer visibility culling: skip entities on invisible/frozen layers
            if let Some(layer) = layer_table.get(layer_ref.0) {
                if !layer.visible || layer.frozen { continue; }
            }
            if let Some(def) = block_table.get(block_ref.definition) {
                let is_sel = u32::from(selection.selected.contains(&entity));
                for block_entity in &def.entities {
                    match block_entity {
                        BlockEntity::Line(start, end, props, layer) => {
                            let transformed_start = block_ref.transform.apply_to_point(*start);
                            let transformed_end = block_ref.transform.apply_to_point(*end);
                            // Resolve color from props/layer (using block_entity helper)
                            line_out.push(EntityVertex {
                                position: [transformed_start.x as f32, transformed_start.y as f32],
                                color: {
                                    let c = PropertyResolver::resolve_color_direct(props, layer, layer_table, Some(block_ref));
                                    [c.r, c.g, c.b, c.a]
                                },
                                is_selected: is_sel,
                            });
                            line_out.push(EntityVertex {
                                position: [transformed_end.x as f32, transformed_end.y as f32],
                                color: {
                                    let c = PropertyResolver::resolve_color_direct(props, layer, layer_table, Some(block_ref));
                                    [c.r, c.g, c.b, c.a]
                                },
                                is_selected: is_sel,
                            });
                        }
                        // ... similar for Circle, Arc, Polyline
                    }
                }
            }
        }
    }
}

// (resolve_block_entity_color/linewidth/linetype helpers removed in Rev 14;
//  callers now use PropertyResolver::resolve_color_direct etc. directly.)
```

> **Performance Note:** For v0.3.0, block geometry is expanded CPU-side into the shared per-type vertex buffers every frame. This approach maintains single-pass rendering with correct selection highlighting. GPU instancing (deferred to v0.4.0) would eliminate the per-frame vertex regeneration cost for repeated block inserts.

### 6.3.1 Block Insert Spatial & Picking Integration

Block inserts participate in the spatial index and picking pass via their expanded bounding box:

- **SpatialIndex:** `BlockRef` entities register their expanded bounding box (computed from `BlockDef::bounds` transformed by `block_ref.transform.apply_to_bounds()`). The `SpatialIndex::rebuild()` method gains a new query branch for `BlockRef` components and requires a `&BlockTable` parameter.

```rust
/// Rebuild the index from the current ECS world state.
/// v0.3.0: also queries BlockRef entities, computing expanded bounding
/// boxes via BlockTable lookups.
pub fn rebuild(&mut self, world: &hecs::World, block_table: &BlockTable) {
    let mut entries: Vec<SpatialEntry> = Vec::new();
    let mut new_bounds: HashMap<hecs::Entity, BoundingBox2D> = HashMap::new();

    // ... existing queries for LineData, CircleData, ArcData, PolylineData ...

    // NEW — v0.3.0: BlockRef entities
    for (entity, (block_ref, _)) in world.query::<(&BlockRef, &Renderable)>().iter() {
        if let Some(def) = block_table.get(block_ref.definition) {
            let bb = block_ref.transform.apply_to_bounds(&def.bounds);
            new_bounds.insert(entity, bb);
            entries.push(SpatialEntry { entity, bounds: bb });
        }
    }

    self.tree = RTree::bulk_load(entries);
    self.bounds = new_bounds;
    self.dirty = false;
}
```

> **Note:** Callers (`ForgeApp`, block editor, explode flow) must pass `&block_table` to `rebuild()`.

- **GPU Picking:** The picking pass expands `BlockDef` entities with the `BlockRef` entity's instance index, rendering transformed geometry into the picking framebuffer. The picking pass iteration includes `BlockRef` entities alongside `LineData`/`CircleData`/`ArcData`/`PolylineData` entities. The `BlockRenderer::expand_for_picking()` method writes `PickingVertex` entries (position + entity_id format compatible with picking.wgsl, NOT EntityVertex format):

```rust
pub fn expand_for_picking(
    &self,
    world: &World,
    block_table: &BlockTable,
    out_vertices: &mut Vec<PickingVertex>,
    instance_offset: u32,
) {
    let mut query = world.query::<(&BlockRef, &Renderable)>();
    for (entity, (block_ref, _)) in query.iter() {
        if let Some(def) = block_table.get(block_ref.definition) {
            for block_entity in &def.entities {
                let (start, end) = match block_entity {
                    BlockEntity::Line(s, e, _, _) => (s, e),
                    _ => continue, // Circles/arcs/polylines approximated as bounding box in v0.3.0
                };
                let ts = block_ref.transform.apply_to_point(*start);
                let te = block_ref.transform.apply_to_point(*end);
                out_vertices.push(PickingVertex {
                    position: [ts.x as f32, ts.y as f32],
                    entity_id: instance_offset,
                });
                out_vertices.push(PickingVertex {
                    position: [te.x as f32, te.y as f32],
                    entity_id: instance_offset,
                });
            }
        }
    }
}
```

> **Note:** This method writes `PickingVertex` (position + entity_id) format compatible with picking.wgsl, NOT `EntityVertex` format.

- **SnapEngine:** Snap candidate generation queries the spatial index and may match a `BlockRef` entity's bounding box entry. For v0.3.0, snap candidates for block inserts are limited to the block's bounding box center and base point; per-entity snap points within blocks are deferred to v0.3.1.

### 6.4 Block Editor

In-place block editing mode:

```rust
// src/block/editor.rs
pub struct BlockEditorState {
    pub active: bool,
    pub editing_block: BlockId,
    pub original_entities: Vec<BlockEntity>, // For cancel/restore
}

impl BlockEditorState {
    pub fn enter(&mut self, block_id: BlockId, block_table: &BlockTable) {
        if let Some(def) = block_table.get(block_id) {
            self.editing_block = block_id;
            self.original_entities = def.entities.clone();
            // Implementation Note: For blocks with 10,000+ entities, this clone allocates
            // significant memory and CPU time. A shallow-copy or reference-counted strategy
            // is deferred to v0.4.0.
            self.active = true;
        }
    }

    pub fn save(&mut self, block_table: &mut BlockTable, history: &mut History) -> Result<(), BlockError> {
        let def = block_table.definitions.get_mut(&self.editing_block)
            .ok_or(BlockError::BlockNotFound)?;
        // Capture old state before compute_bounds() mutates bounds
        let old_def = BlockDef {
            name: def.name.clone(),
            base_point: def.base_point,
            entities: self.original_entities.clone(),
            bounds: def.bounds,
        };
        def.compute_bounds();
        // Construct new BlockDef from current state
        let new_def = BlockDef {
            name: def.name.clone(),
            base_point: def.base_point,
            entities: def.entities.clone(),
            bounds: def.bounds,
        };
        let tx = Transaction {
            label: format!("Edit block '{}'", old_def.name),
            ops: vec![AtomicOp::ModifyBlockDef {
                block_id: self.editing_block,
                old: old_def,
                new: new_def,
            }],
        };
        history.push(tx);
        self.active = false;
        Ok(())
    }

    pub fn cancel(&mut self, block_table: &mut BlockTable) {
        if let Some(def) = block_table.definitions.get_mut(&self.editing_block) {
            def.entities = self.original_entities.clone();
        }
        self.active = false;
    }
}
```

> **Block Editor Rendering:** During block editing, the viewport renders ONLY the block definition's entities (not the main drawing entities). A light-colored overlay border indicates editing mode. The status bar shows `[Block Editor: <block_name>]`. Exiting via `save()` or `cancel()` returns to the full drawing and re-generates the spatial index for all block inserts (since entity bounds may have changed).


### 6.5 Explode

```rust
// src/block/explode.rs
use hecs::World;

/// Convert a BlockInsert into its constituent entities in the main World.
pub fn explode_block_insert(
    world: &mut World,
    layer_table: &LayerTable,
    block_table: &BlockTable,
    insert_entity: hecs::Entity,
    block_ref: &BlockRef,
) -> Vec<hecs::Entity> {
    let mut spawned = Vec::new();

    if let Some(def) = block_table.get(block_ref.definition) {
        for block_entity in &def.entities {
            // Apply block_ref.transform to geometry
            // Spawn into main World with resolved layer and properties
            // Exploded entities inherit the BlockRef entity's LayerRef.
            // Rationale: After explode, entities are first-class citizens in the
            // main world and should participate in the current layer context.
            // The block definition's original layer assignment is discarded.
            let insert_layer = match world.query_one::<&LayerRef>(insert_entity).get() {
                Ok(Some(lr)) => *lr,
                _ => LayerRef::default(),
            };
            let new_entity = match block_entity {
                BlockEntity::Line(start, end, _props, _layer) => {
                    let ts = block_ref.transform.apply_to_point(*start);
                    let te = block_ref.transform.apply_to_point(*end);
                    world.spawn((
                        LineData { start: ts, end: te, color: Color::WHITE, width: 1.0 },
                        LayerRef(insert_layer.0),
                        PropertySource::default(),
                        Renderable,
                    ))
                }
                BlockEntity::Circle(center, radius, _props, _layer) => {
                    let tc = block_ref.transform.apply_to_point(*center);
                    world.spawn((
                        CircleData { center: tc, radius: radius * block_ref.transform.scale.x,  // uniform scale assumption for v0.3.0
                                    color: Color::WHITE, width: 1.0 },
                        LayerRef(insert_layer.0),
                        PropertySource::default(),
                        Renderable,
                    ))
                }
                BlockEntity::Arc(center, radius, start_angle, end_angle, _props, _layer) => {
                    let tc = block_ref.transform.apply_to_point(*center);
                    world.spawn((
                        ArcData { center: tc, radius: radius * block_ref.transform.scale.x,  // uniform scale assumption for v0.3.0
                                    start_angle: *start_angle + block_ref.transform.rotation_degrees,
                                    end_angle: *end_angle + block_ref.transform.rotation_degrees,
                                    color: Color::WHITE, width: 1.0 },
                        LayerRef(insert_layer.0),
                        PropertySource::default(),
                        Renderable,
                    ))
                }
                BlockEntity::Polyline(vertices, closed, _props, _layer) => {
                    let tv: Vec<Point2D> = vertices.iter()
                        .map(|v| block_ref.transform.apply_to_point(*v))
                        .collect();
                    world.spawn((
                        PolylineData { vertices: tv, closed: *closed, color: Color::WHITE, width: 1.0 },
                        LayerRef(insert_layer.0),
                        PropertySource::default(),
                        Renderable,
                    ))
                }
            };
            spawned.push(new_entity);
        }
    }

    // Despawn the insert entity
    world.despawn(insert_entity).ok();
    spawned
}
```

```rust
// src/property/match_props.rs
use hecs::World;

/// Copy all display properties from source entity to target entities.
/// All mutations are recorded in a single Transaction and pushed to History.
pub fn match_properties(
    world: &mut World,
    source: hecs::Entity,
    targets: &[hecs::Entity],
    history: &mut History,
) -> Result<(), PropertyError> {
    let source_props = match world.query_one::<&PropertySource>(source).get() {
        Ok(Some(props)) => props.clone(),
        _ => return Err(PropertyError::NoSource),
    };
    let source_layer = match world.query_one::<&LayerRef>(source).get() {
        Ok(Some(lr)) => Some(*lr),
        _ => None,
    };

    let mut tx = Transaction::new("Match properties");

    for &target in targets {
        if let Ok(Some(mut target_props)) = world.query_one::<&mut PropertySource>(target).get() {
            let old = *target_props;  // capture old
            target_props.color = source_props.color;
            target_props.linewidth = source_props.linewidth;
            target_props.linetype = source_props.linetype;
            tx.push(AtomicOp::SetPropertySource { entity: target, old, new: *target_props });
        }
        if let Ok(Some(mut target_layer)) = world.query_one::<&mut LayerRef>(target).get() {
            if let Some(source_layer) = source_layer {
                let old = target_layer.0;  // capture old
                target_layer.0 = source_layer.0;
                tx.push(AtomicOp::SetLayerRef { entity: target, old, new: target_layer.0 });
            }
        }
    }

    history.push(tx);
    Ok(())
}
```

## 8. Advanced Draw Commands

### 8.0 CommandResult Extension

The `CommandResult` enum (originally defined in v0.2.0) is extended with a new variant for commands that produce undoable transactions:

```rust
/// Updated for v0.3.0 — added CompleteWithTransaction variant.
pub enum CommandResult {
    Continue,
    Complete,
    CompleteWithTransaction(Transaction),  // New: carries undo data
    Cancelled,
    Error(String),
}
```

> **Note:** ForgeApp's command dispatch must match on `CompleteWithTransaction` and push the enclosed `Transaction` to `History`, rather than pushing an empty `Complete` result.
>
> ```rust
> // In ForgeApp::handle_command_result (app.rs):
> fn handle_command_result(&mut self, result: CommandResult) {
>     match result {
>         CommandResult::Continue => { /* keep command active */ }
>         CommandResult::Complete => {
>             // v0.2.0 pattern: command already applied mutation internally
>             self.command_state.active = None;
>         }
>         CommandResult::CompleteWithTransaction(tx) => {
>             // v0.3.0 pattern: command produces explicit undoable transaction
>             self.history.push(tx);
>             self.command_state.active = None;
>         }
>         CommandResult::Cancelled => {
>             self.command_state.active = None;
>         }
>         CommandResult::Error(msg) => {
>             self.command_state.last_error = Some(msg);
>         }
>     }
> }
> ```
>
> **Migration note:** All match arms on `CommandResult` must handle the new `CompleteWithTransaction` variant.

```rust
// src/commands/spline_cmd.rs
pub struct SplineCommand {
    points: Vec<Point2D>,
    selected_layer: LayerId,
}

impl Command for SplineCommand {
    fn name(&self) -> &'static str { "SPLINE" }
    fn prompt(&self) -> String {
        if self.points.len() < 2 {
            "Specify points (Enter to finish):".into()
        } else {
            "Specify next point or press Enter to finish:".into()
        }
    }
    fn steps_remaining(&self) -> usize { usize::MAX } // Variable number of steps

    fn on_input(&mut self, input: CommandInput, world: &mut World, layer_table: &LayerTable) -> CommandResult {
        match input {
            CommandInput::Point(p) => {
                self.points.push(p);
                CommandResult::Continue
            }
            // Close the spline: add a segment back to the first point
            // and mark as closed (triggered by "C" input, mapped to Confirm with close flag)
            CommandInput::Confirm if self.points.len() >= 2 => {
                // Catmull-Rom to Cubic Bezier conversion
                // For n fit points, n-1 cubic bezier segments are produced
                let mut bezier_segments: Vec<CubicBezier> = Vec::new();
                for i in 0..self.points.len() - 1 {
                    let p0 = if i == 0 { self.points[0] } else { self.points[i - 1] };
                    let p1 = self.points[i];
                    let p2 = self.points[i + 1];
                    let p3 = if i + 2 < self.points.len() { self.points[i + 2] } else { self.points[self.points.len() - 1] };

                    // Catmull-Rom tension = 0.5 (centripetal)
                    let tension = 0.5;
                    let cp1 = Point2D::new(
                        p1.x + (p2.x - p0.x) * tension,
                        p1.y + (p2.y - p0.y) * tension,
                    );
                    let cp2 = Point2D::new(
                        p2.x - (p3.x - p1.x) * tension,
                        p2.y - (p3.y - p1.y) * tension,
                    );
                    bezier_segments.push(CubicBezier { p0: p1, p1: cp1, p2: cp2, p3: p2 });
                }

                // Approximate each segment and flatten
                let mut vertices: Vec<Point2D> = Vec::new();
                for (seg_i, seg) in bezier_segments.iter().enumerate() {
                    let pts = seg.to_polyline(64);
                    // For the first segment, take all points; for subsequent,
                    // skip the first point (duplicate of previous segment's last)
                    for (j, pt) in pts.iter().enumerate() {
                        if seg_i == 0 || j > 0 {
                            vertices.push(*pt);
                        }
                    }
                }

                let poly = PolylineData { vertices, closed: false, color: Color::WHITE, width: 1.0 };
                let active_layer = LayerRef(self.selected_layer);  // Use selected_layer, not default
                let entity = world.spawn((poly.clone(), active_layer, PropertySource::default(), Renderable));
                let mut tx = Transaction::new("Spline");
                tx.push(AtomicOp::SpawnPolyline { entity, data: poly });
                tx.push(AtomicOp::SetLayerRef { entity, old: LayerId(0), new: self.selected_layer });
                tx.push(AtomicOp::SetPropertySource { entity, old: PropertySource::default(), new: PropertySource::default() });
                CommandResult::CompleteWithTransaction(tx)
            }
            _ => CommandResult::Error("Need at least 2 points for a spline.".into()),
        }
    }
}
```

```rust
// src/geometry/spline.rs
/// Cubic Bezier curve defined by 4 control points.
#[derive(Debug, Clone)]
pub struct CubicBezier {
    pub p0: Point2D,
    pub p1: Point2D,
    pub p2: Point2D,
    pub p3: Point2D,
}

impl CubicBezier {
    pub fn evaluate(&self, t: f64) -> Point2D {
        let u = 1.0 - t;
        let a = u * u * u;
        let b = 3.0 * u * u * t;
        let c = 3.0 * u * t * t;
        let d = t * t * t;
        Point2D::new(
            a * self.p0.x + b * self.p1.x + c * self.p2.x + d * self.p3.x,
            a * self.p0.y + b * self.p1.y + c * self.p2.y + d * self.p3.y,
        )
    }

    /// Approximate as polyline with `segments` vertices.
    pub fn to_polyline(&self, segments: usize) -> Vec<Point2D> {
        (0..=segments)
            .map(|i| self.evaluate(i as f64 / segments as f64))
            .collect()
    }
}
```

```rust
pub struct GripSystem {
    pub handles: Vec<GripHandle>,
    pub active_drag: Option<GripDragState>,

impl GripSystem {
    pub fn regenerate(&mut self, world: &World, selection: &SelectionManager) {
        self.handles.clear();
        for &entity in &selection.selected {
            if let Ok(Some(line)) = world.query_one::<&LineData>(entity).get() {
                self.handles.push(GripHandle {
                    position: line.start,
                    grip_type: GripType::Endpoint,
                    entity,
                    vertex_index: Some(0),
                });
                self.handles.push(GripHandle {
                    position: line.end,
                    grip_type: GripType::Endpoint,
                    entity,
                    vertex_index: Some(1),
                });
                self.handles.push(GripHandle {
                    position: Point2D::new(
                        (line.start.x + line.end.x) / 2.0,
                        (line.start.y + line.end.y) / 2.0,
                    ),
                    grip_type: GripType::Midpoint,
                    entity,
                    vertex_index: None,
                });
            }
            // ... similar for Circle (center + 4 quadrants), Arc (center + endpoints), Polyline (all vertices)
        }
    }

    /// Find the grip handle nearest to the cursor (within 10 screen pixels).
    /// Returns the handle index, or None if no handle is close enough.
    pub fn hit_test(&self, screen_pos: (f32, f32), camera: &CameraState) -> Option<usize> {
        const HIT_RADIUS_PX: f32 = 10.0;
        self.handles.iter().enumerate()
            .filter_map(|(i, h)| {
                let (sx, sy) = camera.world_to_screen(h.position);
                let dist = ((sx - screen_pos.0).powi(2) + (sy - screen_pos.1).powi(2)).sqrt();
                if dist < HIT_RADIUS_PX { Some((i, dist)) } else { None }
            })
            .min_by(|a, b| a.1.partial_cmp(&b.1).unwrap_or(std::cmp::Ordering::Equal))
            .map(|(i, _)| i)
    }
}
```

```rust
pub struct GripDragState {
    pub handle_index: usize,
    pub start_position: Point2D,
    pub current_position: Point2D,
}

impl GripDragState {
    /// Apply the drag delta to the underlying entity.
    pub fn apply(&self, world: &mut World, handles: &[GripHandle]) {
        let handle = &handles[self.handle_index];
        let delta = Point2D::new(
            self.current_position.x - self.start_position.x,
            self.current_position.y - self.start_position.y,
        );

        match handle.grip_type {
            GripType::Endpoint | GripType::Vertex => {
                if let Some(handle) = handles.get(self.handle_index) {
                    if let Some(vi) = handle.vertex_index {
                        // Use vertex_index to identify which part of the geometry to update
                        match handle.grip_type {
                            GripType::Vertex => {
                                // Polyline vertex: index into vertices array
                                if let Ok(Some(mut pl)) = world.query_one::<&mut PolylineData>(handle.entity).get() {
                                    if let Some(v) = pl.vertices.get_mut(vi) {
                                        v.x = handle.position.x + delta.x;
                                        v.y = handle.position.y + delta.y;
                                    }
                                }
                            }
                            GripType::Endpoint => {
                                // Line endpoint: vi=0 for start, vi=1 for end
                                if let Ok(Some(mut line)) = world.query_one::<&mut LineData>(handle.entity).get() {
                                    if vi == 0 {
                                        line.start = handle.position + delta;
                                    } else if vi == 1 {
                                        line.end = handle.position + delta;
                                    }
                                }
                            }
                            _ => {}
                        }
                    }
                }
            }
            GripType::Center => {
                if let Ok(Some(mut circle)) = world.query_one::<&mut CircleData>(handle.entity).get() {
                    circle.center.x += delta.x;
                    circle.center.y += delta.y;
                }
            }
            _ => {}
        }
    }

    /// Snapshot entity data BEFORE the drag begins.
    /// Returns a partially-filled AtomicOp with the old state captured.
    /// Called by the grip system when starting a drag.
    pub fn capture_snapshot(world: &World, handle: &GripHandle) -> Option<AtomicOp> {
        match handle.grip_type {
            GripType::Endpoint | GripType::Midpoint => {
                match world.query_one::<&LineData>(handle.entity).get() {
                    Ok(Some(ld)) => Some(AtomicOp::SetLineData { entity: handle.entity, old: *ld, new: *ld }),
                    _ => None,
                }
            }
            GripType::Center | GripType::Quadrant => {
                match world.query_one::<&CircleData>(handle.entity).get() {
                    Ok(Some(cd)) => Some(AtomicOp::SetCircleData { entity: handle.entity, old: *cd, new: *cd }),
                    _ => None,
                }
            }
            GripType::Vertex => {
                match world.query_one::<&PolylineData>(handle.entity).get() {
                    Ok(Some(pl)) => Some(AtomicOp::SetPolylineData { entity: handle.entity, old: pl.clone(), new: pl.clone() }),
                    _ => None,
                }
            }
        }
    }

    /// Finalize: read the new entity data and complete the Transaction.
    /// Called when the drag ends (mouse release).
    pub fn finalize_transaction(&self, world: &World, snapshot: &mut AtomicOp) {
        match snapshot {
            AtomicOp::SetLineData { entity, ref mut new, .. } => {
                if let Ok(Some(ld)) = world.query_one::<&LineData>(*entity).get() { *new = *ld; }
            }
            AtomicOp::SetCircleData { entity, ref mut new, .. } => {
                if let Ok(Some(cd)) = world.query_one::<&CircleData>(*entity).get() { *new = *cd; }
            }
            AtomicOp::SetPolylineData { entity, ref mut new, .. } => {
                if let Ok(Some(pl)) = world.query_one::<&PolylineData>(*entity).get() { new.clone_from(pl); }
            }
            _ => {}
        }
    }
}
```

### 9.4 Grip Rendering

Grip handles are rendered as 8x8 pixel colored squares in screen space:
- **Endpoint:** Blue square
- **Midpoint:** Green triangle
- **Center:** Red circle
- **Vertex:** Cyan square

```wgsl
    viewport_size: vec2<f32>,

@group(1) @binding(0)
```

### 9.5 Grip-Command Interaction

- Starting any command cancels an active grip drag (the drag state is dropped, any in-flight preview is discarded).
- Pressing Ctrl+Z during a grip drag discards the drag (entity geometry snaps back to pre-drag state).
- Selection changes during an active grip drag are blocked (the grip drag retains its handle reference).
- When a grip drag completes, the change is recorded as a `Transaction` and pushed to `History` via `AtomicOp::SetLineData`/`SetCircleData`/`SetPolylineData` variants (reusing the existing geometry-set ops).
- Grip operations only activate when `command_state.active.is_none()`.

> **Note:** The `GripDragState::capture_snapshot()` / `finalize_transaction()` protocol ensures grip edits are undoable. The snapshot captures old values at drag start; `finalize_transaction()` reads the new values at drag end and completes the `AtomicOp`.

### 9.6 New History AtomicOp Variants (v0.3.0)

The following new variants extend the `AtomicOp` enum (defined in v0.2.0) for layer, property, and block operations:

```rust
pub enum AtomicOp {
    // ... existing variants (SpawnLine, DespawnLine, SetLineData, etc.)

    // NEW — v0.3.0
    SetLayerRef { entity: hecs::Entity, old: LayerId, new: LayerId },
    SetPropertySource { entity: hecs::Entity, old: PropertySource, new: PropertySource },
    SetBlockRef { entity: hecs::Entity, old: BlockRef, new: BlockRef },
    ModifyBlockDef { block_id: BlockId, old: BlockDef, new: BlockDef },
}
```

**History::undo/redo must handle these variants.** The `ModifyBlockDef` variant stores full `BlockDef` structs (not just `Vec<BlockEntity>`) because undo/redo must restore the complete block definition including computed bounds and metadata.

`History::undo` and `History::redo` gain a `block_table: &mut BlockTable` parameter:

```rust
impl History {
    pub fn undo(&mut self, world: &mut World, block_table: &mut BlockTable) -> Option<String> { ... }
    pub fn redo(&mut self, world: &mut World, block_table: &mut BlockTable) -> Option<String> { ... }
}
```

**Undo match arms (inside `undo()`, applied in reverse order):**
```rust
AtomicOp::SetLayerRef { entity, old, new: _ } => {
    world.insert_one(*entity, LayerRef(*old)).ok();
}
AtomicOp::SetPropertySource { entity, old, new: _ } => {
    world.insert_one(*entity, old.clone()).ok();
}
AtomicOp::SetBlockRef { entity, old, new: _ } => {
    world.insert_one(*entity, *old).ok();
}
AtomicOp::ModifyBlockDef { block_id, old, new: _ } => {
    if let Some(def) = block_table.definitions.get_mut(block_id) {
        *def = old.clone();
    }
}
```

**Redo match arms (applied in forward order):**
```rust
AtomicOp::SetLayerRef { entity, old: _, new } => {
    world.insert_one(*entity, LayerRef(*new)).ok();
}
AtomicOp::SetPropertySource { entity, old: _, new } => {
    world.insert_one(*entity, new.clone()).ok();
}
AtomicOp::SetBlockRef { entity, old: _, new } => {
    world.insert_one(*entity, *new).ok();
}
AtomicOp::ModifyBlockDef { block_id, old: _, new } => {
    if let Some(def) = block_table.definitions.get_mut(block_id) {
        *def = new.clone();
    }
}
```

**Migration note:** The `History::undo()`/`redo()` signature change from `(&mut World)` to `(&mut World, &mut BlockTable)` requires updates to all callers in `ForgeApp`, particularly the undo/redo keyboard shortcut handlers and the `apply_entity_remapping` function.

The `SetBlockRef` variant is used by the BLOCK and INSERT commands. The `ModifyBlockDef` variant is used by the block editor's `save()` method. The `SetLayerRef` variant is used by the Property Palette's layer reassignment and the Layer Panel's drag-to-reassign feature.

```rust
            array_stride: 32,
            step_mode: wgpu::VertexStepMode::Vertex,

            label: Some("linetype pipeline"),

                module: &shader,
                entry_point: "fs_main",

                    format: config.format,
                    blend: Some(wgpu::BlendState::ALPHA_BLENDING),

            primitive: wgpu::PrimitiveState {
                topology: wgpu::PrimitiveTopology::LineList,
                ..Default::default()
            },
            depth_stencil: None,
            multisample: wgpu::MultisampleState::default(),
            multiview: None,

            label: Some("linetype vertex buffer"),
            size: 1024,
            usage: wgpu::BufferUsages::VERTEX | wgpu::BufferUsages::COPY_DST,
            mapped_at_creation: false,
        });

        let index_buffer = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("linetype index buffer"),
            size: 1024,
            usage: wgpu::BufferUsages::INDEX | wgpu::BufferUsages::COPY_DST,

            vertex_buffer,
            index_buffer,

        let mut render_pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
            label: Some("linetype render pass"),
            color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                view,
                resolve_target: None,
                ops: wgpu::Operations {
                    load: wgpu::LoadOp::Load,
                    store: wgpu::StoreOp::Store,
                },

            depth_stencil_attachment: None,
            timestamp_writes: None,
            occlusion_query_set: None,

        render_pass.set_bind_group(0, camera_bind_group, &[]);

        render_pass.set_index_buffer(self.index_buffer.slice(..), wgpu::IndexFormat::Uint32);
        render_pass.draw_indexed(0..self.num_indices, 0, 0..1);
    }
}
```

### 10.2 Linetype WGSL Shader

```wgsl
// src/render/shaders/linetype.wgsl
struct CameraUniform {
    view_proj: mat4x4<f32>,
};
@group(0) @binding(0)
var<uniform> camera: CameraUniform;

struct VertexInput {
    @location(0) position: vec2<f32>,
    @location(1) color: vec4<f32>,
    @location(2) linetype: u32,
    @location(3) linetype_scale: f32,
};

struct VertexOutput {
    @builtin(position) clip_position: vec4<f32>,
    @location(0) color: vec4<f32>,
    @location(1) @interpolate(flat) linetype: u32,
    @location(2) @interpolate(flat) linetype_scale: f32,
};

@vertex
fn vs_main(in: VertexInput) -> VertexOutput {
    var out: VertexOutput;
    out.clip_position = camera.view_proj * vec4<f32>(in.position, 0.0, 1.0);
    out.color = in.color;
    out.linetype = in.linetype;
    out.linetype_scale = in.linetype_scale;
    return out;
}

// Linetype pattern bit masks for stipple
// 0xFFFF = solid, 0x3333 = dotted, 0x0F0F = dashed, 0x1B1B = dash-dot
fn linetype_pattern(linetype: u32) -> u32 {
    var pattern: u32;
    switch linetype {
        case 0u: { pattern = 0xFFFFu; }     // Solid
        case 1u: { pattern = 0x3333u; }     // Dotted
        case 2u: { pattern = 0x0F0Fu; }     // Dashed
        case 3u: { pattern = 0x1B1Bu; }     // Dash-dot
        case 4u: { pattern = 0xAAAAu; }     // Border
        case 5u: { pattern = 0xCCCCu; }     // Center
        default: { pattern = 0xFFFFu; }     // Default solid
    }
    return pattern;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    let pattern = linetype_pattern(in.linetype);
    let frag_coord = vec2<f32>(floor(in.clip_position.x), floor(in.clip_position.y));
    // Screen-space derivative gives consistent stipple advance across any line angle.
    // Replaces Manhattan-distance approach which broke for diagonal lines.
    let line_deriv = normalize(dpdx(in.clip_position.xy) + dpdy(in.clip_position.xy));
    let pattern_coord = dot(frag_coord, line_deriv);
    let pattern_bit = u32(i32(floor(pattern_coord / max(1.0, in.linetype_scale)))) & 15u;
    let mask_bit = (pattern >> pattern_bit) & 1u;
    if mask_bit == 0u {
        discard;
    }
    return in.color;
}
```

## 16. Risk Assessment

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| **Block insert entity ID explosion** | Medium | High | Block inserts are single entities; explode generates many. Spatial index rebuild after explode may stall. Batch rebuild + progress indicator. |
| **PropertyResolver per-frame overhead** | Medium | Medium | Cache resolved properties via HashMap<Entity, ResolvedProperties>; invalidate on PropertySource/LayerRef change or layer property mutation (§5.4). |
| **Grip handle clutter** | Medium | Low | Cap visible grips to nearest N; fade distant grips. |
| **Linetype shader aliasing** | Medium | Low | Pattern computed in screen space; may shimmer at low zoom. Add min-dash-length clamp. |
| **BlockDef serialization for history** | Medium | Medium | BlockDef contains Vec<BlockEntity>; clone on undo. Acceptable for v0.3.0. |
| **Layer delete with referenced entities** | Medium | High | LayerTable::delete() checks reference count parameter. ForgeApp queries ECS for LayerRef references before calling delete(). |
| **Nested block recursion** | Low | Medium | Descoped to v0.3.1. Risk table item kept for tracking. In v0.3.0, block definitions may contain Line/Circle/Arc/Polyline only — no nesting. |
| **BlockRef invisible to picking/spatial** | Medium | High | Picking pass expands block geometry with BlockRef instance index; SpatialIndex registers expanded bounding box (§6.3.1). |
| **Block editor bypasses undo/redo** | Medium | High | BlockEditorState::save() builds AtomicOp::ModifyBlockDef and pushes to History (§6.4). |
| **Transform2D undefined** | ~~High~~ Low | ~~High~~ Low | Resolved in Rev 2 — Transform2D fully specified in §6.2 with identity, apply_to_point, apply_to_bounds. |
| **ByBlock property resolution stubbed** | High | High | Single-level ByBlock resolution implemented; walks up to parent BlockRef entity (§5.4). |

## 18. Appendix: v0.2.0 to v0.3.0 Migration Guide

### Breaking Changes

| `SpatialIndex::rebuild(&mut self, world)` → `rebuild(&mut self, world, block_table)` | Added `block_table: &BlockTable` parameter for block entity spatial indexing |
| `SpatialIndex` struct | Added `bounds: HashMap<hecs::Entity, BoundingBox2D>` field for block insert bounding box lookups |
| `PropertyResolver::resolve_*_direct(..., parent_entity: hecs::Entity)` → `resolve_*_direct(...)` | Removed unused `parent_entity` parameter from all three direct-resolution methods |
| `History::undo/redo(&mut self, world)` → `undo/redo(&mut self, world, block_table)` | Added `block_table: &mut BlockTable` parameter for ModifyBlockDef support |

### New Systems to Initialize

In `ForgeApp::new()`, add:

```rust
let layer_manager = LayerManager::new();
let block_manager = BlockManager::new();
let property_palette = PropertyPalette::new();
let grip_system = GripSystem::new();
```

### Updated Render Loop

Add before entity pass:

```
// Layer visibility culling is handled inside EntityRenderer during vertex generation.
// The renderer checks layer_table.get(layer_ref.0)?.visible for each entity and
// skips invisible layers at the per-entity level, avoiding a separate pre-pass allocation.
```

Add after entity pass:

```rust
// Grip handles
self.render_state.grip_renderer.render(&mut encoder, &view, &self.grip_system);
```

### Command Trait Extension

`Command::on_input` is extended with a `layer_table: &LayerTable` parameter for v0.3.0 commands:

```rust
// v0.2.0 signature:
fn on_input(&mut self, input: CommandInput, world: &mut World) -> CommandResult;

// v0.3.0 signature:
fn on_input(&mut self, input: CommandInput, world: &mut World, layer_table: &LayerTable) -> CommandResult;
```

All v0.2.0 commands must accept the new parameter (can be `_` unused in their implementations). The call site in ForgeApp's command dispatch must also pass `&layer_manager.table` when invoking `on_input`:

```rust
// ForgeApp command dispatch — pass layer_table to all command on_input calls:
fn dispatch_input(&mut self, input: CommandInput) {
    if let Some(ref mut cmd) = self.command_state.active {
        let result = cmd.on_input(input, &mut self.world, &self.layer_manager.table);
        self.handle_command_result(result);
    }
}
```

> **Migration note:** Commands that spawn entities on a specific layer should capture `layer_manager.table.active_layer` at construction time (passed via constructor), rather than querying the table during `on_input`.
