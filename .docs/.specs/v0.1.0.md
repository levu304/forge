# Forge v0.1.0 Technical Specification (Revised)

> **Foundation — The Viewport**  
> *A cross-platform 2D CAD viewport with ECS-backed geometry, command-driven interaction, and a 60fps wgpu render pipeline.*  
> **Revision Date:** 2026-05-21 — Rev 11 (9th adversarial review applied — 6 findings fixed, see §17).

---

## 1. Scope & Objectives

### 1.1 In Scope
- Cross-platform native window (Linux, macOS, Windows)
- wgpu-based 2D render pipeline with orthographic camera
- Entity-Component-System (ECS) for geometry storage
- Four primitive entities: Line, Circle, Arc, Polyline
- Mouse/keyboard input handling
- Grid visualization with configurable spacing
- Command-line parser and dispatcher (`LINE`, `CIRCLE`, `ARC`, `PLINE`)
- Status bar, toolbar placeholder, and property inspector stub
- 60fps viewport performance target

### 1.2 Out of Scope
- Selection system (v0.2.0)
- Snapping engine (v0.2.0)
- Modify commands (MOVE, ERASE, etc.) (v0.2.0)
- Undo/redo (v0.2.0)
- Layer system (v0.3.0)
- File I/O (v0.5.0)
- WebAssembly build (v1.2.0)
- Constraint solving (v0.7.0)

## 3. Crate Selection & Justification

| Crate | Version | Purpose | Rationale |
|-------|---------|---------|-----------|
| `winit` | 0.30 | Windowing & event loop | De-facto standard; `ApplicationHandler` trait for structured lifecycle |
| `wgpu` | 0.29 | GPU abstraction | Unified API over Vulkan/Metal/DX12/WebGPU; MSRV 1.87 |
| `hecs` | 0.10 | ECS framework | Minimal, fast, archetype-based; battle-tested |
| `nalgebra` | 0.34 | Linear algebra | Mature, generic, excellent 2D/3D math |
| `nom` | 8 | Command parser | Zero-copy parser combinators; function-based architecture |
| `egui` | 0.34 | Immediate-mode UI | Lightweight; integrates with wgpu; perfect for CAD panels |
| `egui-wgpu` | 0.34 | egui-wgpu bridge | Official integration; handles render pass injection |
| `egui-winit` | 0.34 | egui-winit bridge | Event translation; pointer mapping |
| `thiserror` | 2 | Error definitions | Ergonomic custom error types |
| `tracing` | 0.1 | Structured logging | Performance profiling; structured diagnostics |
| `pollster` | 0.4 | Async block executor | Synchronous wgpu adapter request on main thread |
| `bytemuck` | 1.25 | Safe type casting | `Pod`/`Zeroable` derives for GPU buffer uploads |

### Rejected Alternatives

| Alternative | Rejected Because |
|-------------|-----------------|
| `bevy` (full engine) | Too heavy; we need a CAD engine, not a game engine. `hecs` is the minimal ECS we need |
| `macroquad` | Too high-level; we need direct wgpu control for CAD-specific rendering |
| `glam` | Good for games, but `nalgebra` offers better precision types and transform APIs for CAD |
| `winnow` (over `nom`) | `winnow` is excellent but `nom` v8's function-based API is mature and well-documented |
| `iced` (over `egui`) | `iced` is retained-mode and more complex; `egui` is faster to iterate for v0.1.0 |

```rust
// src/geometry/point.rs
/// CAD-grade 2D point using f64 for precision.
/// All world-space coordinates use this type.
#[derive(Debug, Clone, Copy, PartialEq, Default)]
pub struct Point2D {
    pub x: f64,
    pub y: f64,
}

impl Point2D {
    pub fn new(x: f64, y: f64) -> Self { Self { x, y } }
    pub fn to_f32_array(&self) -> [f32; 2] {
        [self.x as f32, self.y as f32]
    }
}

// src/geometry/bounds.rs
/// Axis-aligned bounding box for culling and fit-to-view.
#[derive(Debug, Clone, Copy)]
pub struct BoundingBox2D {
    pub min: Point2D,
    pub max: Point2D,
}

impl BoundingBox2D {
    pub fn is_empty(&self) -> bool {
        self.min.x >= self.max.x || self.min.y >= self.max.y
    }
    pub fn center(&self) -> Point2D {
        Point2D::new(
            (self.min.x + self.max.x) / 2.0,
            (self.min.y + self.max.y) / 2.0,
        )
    }
    /// Expand this bounding box to include another.
    /// If either is empty, returns the non-empty one.
    pub fn union(&self, other: &Self) -> Self {
        if self.is_empty() {
            return *other;
        }
        if other.is_empty() {
            return *self;
        }
        Self {
            min: Point2D::new(
                self.min.x.min(other.min.x),
                self.min.y.min(other.min.y),
            ),
            max: Point2D::new(
                self.max.x.max(other.max.x),
                self.max.y.max(other.max.y),
            ),
        }
    }
}
```

```rust
// src/ecs/resources.rs
use crate::geometry::*;

/// Camera configuration and state.
#[derive(Debug, Clone)]
pub struct CameraState {
    /// World-space center of the view.
    pub target: Point2D,
    /// Zoom factor: 1.0 = 1 world unit per screen pixel at 1:1.
    pub zoom: f64,
    /// Viewport dimensions in physical pixels.
    pub viewport_size: (u32, u32),
    /// Background clear color.
    pub clear_color: Color,
}

impl CameraState {
    /// Convert screen pixel (top-left origin) to world space.
    ///
    /// `screen` is in physical (non-scaled) pixels.
    /// Uses the current zoom and target to invert the view-projection.
    pub fn screen_to_world(&self, screen: (f32, f32)) -> Point2D {
        if self.viewport_size.0 == 0 || self.viewport_size.1 == 0 {
            return Point2D::default();
        }
        let half_w = self.viewport_size.0 as f64 / 2.0;
        let half_h = self.viewport_size.1 as f64 / 2.0;

        // Normalise screen coords to [-1, 1] with Y flip
        let ndc_x = (screen.0 as f64 / half_w) - 1.0;
        let ndc_y = 1.0 - (screen.1 as f64 / half_h); // flip Y

        // Inverse of ortho projection * view translation
        Point2D::new(
            self.target.x + ndc_x * half_w / self.zoom,
            self.target.y + ndc_y * half_h / self.zoom,
        )
    }

    /// Convert world space to screen pixel (top-left origin).
    pub fn world_to_screen(&self, world: Point2D) -> (f32, f32) {
        if self.viewport_size.0 == 0 || self.viewport_size.1 == 0 {
            return (0.0, 0.0);
        }
        let half_w = self.viewport_size.0 as f64 / 2.0;
        let half_h = self.viewport_size.1 as f64 / 2.0;

        let dx = world.x - self.target.x;
        let dy = world.y - self.target.y;

        let sx = half_w + dx * self.zoom;
        let sy = half_h - dy * self.zoom; // flip Y

        (sx as f32, sy as f32)
    }

    /// Compute view-projection matrix (f32 for GPU).
    ///
    /// `nalgebra::Matrix4<f32>` is column-major, which matches WGSL's
    /// default matrix layout (column vectors read with `mat.data[col]`).
    ///
    /// ## Rationale for `nalgebra::Orthographic3`
    /// This type is designed for 3D orthographic projection but is perfectly
    /// suitable for 2D when z=0. We use it instead of manual matrix construction
    /// because it handles near/far clipping and coordinate conventions correctly.
    ///
    /// NOTE: The orthographic bounds are computed relative to `self.target`,
    /// so the projection itself encodes the camera position. No separate view
    /// translation is needed — applying one would double-translate and break pan.
    pub fn view_proj_matrix(&self) -> nalgebra::Matrix4<f32> {
        // Defensive: prevent division by zero if zoom is uninitialized.
        let z = self.zoom.max(0.0001);
        let half_w = (self.viewport_size.0 as f64) / (2.0 * z);
        let half_h = (self.viewport_size.1 as f64) / (2.0 * z);

        let left = (self.target.x - half_w) as f32;
        let right = (self.target.x + half_w) as f32;
        let bottom = (self.target.y - half_h) as f32;
        let top = (self.target.y + half_h) as f32;

        let proj = nalgebra::Orthographic3::new(left, right, top, bottom, -1.0, 1.0);
        proj.as_matrix().clone()
    }
}
```

### 6.1 Command State Machine

```rust
// src/commands/mod.rs
use hecs::World;
use crate::geometry::Point2D;
use crate::util::Color;

/// Lightweight descriptor for preview geometry drawn during command
/// execution (e.g., rubber-band line, temporary circle outline).
pub struct PreviewEntity {
    pub points: Vec<Point2D>,
    pub color: Color,
    pub width: f32,
}

/// A command is an interactive operation with multiple steps.
/// Each step prompts the user for input (point, distance, angle, etc.).
///
/// NOTE: Send + Sync not required in v0.1.0 (single-threaded event loop).
/// Add bounds if commands are dispatched across threads in v0.2.0+.
pub trait Command {
    /// Command name used in CLI (e.g., "LINE", "CIRCLE").
    fn name(&self) -> &'static str;
    /// Human-readable prompt for current step.
    fn prompt(&self) -> String;
    /// Number of steps remaining (0 = complete).
    fn steps_remaining(&self) -> usize;
    /// Process a user input event (point pick, text entry, etc.).
    fn on_input(&mut self, input: CommandInput, world: &mut World) -> CommandResult;
    /// Cancel the command, cleaning up any preview entities.
    fn on_cancel(&mut self, world: &mut World);
    /// Render preview geometry (e.g., rubber-band line).
    fn preview(&self) -> Vec<PreviewEntity>;
}

pub enum CommandInput {
    Point(Point2D),           // Mouse click or typed coordinate
    Text(String),             // Command-line text entry
    #[allow(dead_code)]
    Distance(f64),            // Typed distance value (reserved: CIRCLE radius, etc.)
    #[allow(dead_code)]
    Angle(f64),               // Typed angle in degrees (reserved: ARC rotation)
    Cancel,                   // Escape key
    Confirm,                  // Enter key
}

pub enum CommandResult {
    Continue,                 // Await next input
    Complete,                 // Command finished successfully
    Error(String),            // Invalid input, show error, continue
    Cancelled,                // User cancelled
}

/// Manages the active command and command history.
pub struct CommandState {
    pub active: Option<Box<dyn Command>>,
    pub history: Vec<String>, // Previous command strings
    pub buffer: String,       // Current command-line text
    pub last_error: Option<String>, // Most recent command error (displayed in UI)
    pub pending_dispatch: Option<String>, // Text waiting to be dispatched from UI command line
}

impl Default for CommandState {
    fn default() -> Self {
        Self {
            active: None,
            history: Vec::new(),
            buffer: String::new(),
            last_error: None,
            pending_dispatch: None,
        }
    }
}
```

### 6.2 Command Grammar (nom v8)

```rust
// src/commands/parser.rs
use nom::{
    IResult,
    Parser,
    branch::alt,
    bytes::complete::tag_no_case,
    character::complete::{char, space0, space1},
    combinator::{map, opt},
    number::complete::float,        // nom 8: float is in number::complete
    sequence::{preceded, tuple},
};
use crate::geometry::Point2D;

/// The result of parsing a command invocation.
#[derive(Debug, Clone, PartialEq)]
pub enum ParsedCommand {
    Line(LineArgs),
    Circle(CircleArgs),
    Arc(ArcArgs),
    Polyline(PolylineArgs),
}

#[derive(Debug, Clone, PartialEq)]
pub struct LineArgs {
    pub start: Option<Point2D>,  // None if just "LINE" with no args
    pub end: Option<Point2D>,
}

#[derive(Debug, Clone, PartialEq)]
pub struct CircleArgs {
    pub center: Option<Point2D>,
    pub radius: Option<f64>,
}

#[derive(Debug, Clone, PartialEq)]
pub struct ArcArgs {
    pub center: Option<Point2D>,
    pub radius: Option<f64>,
    pub start_angle: Option<f64>,
    pub end_angle: Option<f64>,
}

#[derive(Debug, Clone, PartialEq)]
pub struct PolylineArgs {
    pub vertices: Vec<Point2D>,
    pub closed: bool,
}

/// Parse a 2D point from strings like:
/// - "10,20"
/// - "10.5, 20.3"
pub fn parse_point(input: &str) -> IResult<&str, Point2D> {
    tuple((
        float,
        preceded(space0, char(',')),
        preceded(space0, float),
    ))
    .map(|(x, _, y)| Point2D::new(x as f64, y as f64))
    .parse(input)
}

/// Parse a command invocation:
/// - "LINE"
/// - "LINE 0,0 100,100"
/// - "L" (alias)
/// - "CIRCLE 50,50 25"
pub fn parse_command(input: &str) -> IResult<&str, ParsedCommand> {
    let (input, _) = space0.parse(input)?;

    // Match command name (case-insensitive)
    let (rest, cmd_token) = alt((
        tag_no_case("LINE"),
        tag_no_case("L"),
        tag_no_case("CIRCLE"),
        tag_no_case("C"),
        tag_no_case("ARC"),
        tag_no_case("A"),
        tag_no_case("PLINE"),
        tag_no_case("PL"),
    ))
    .parse(input)?;

    // Optionally consume whitespace after the command name.
    // Accepts both "LINE" (bare command, no args) and "LINE 0,0 100,100".
    let (rest, _) = opt(space1).parse(rest)?;

    match cmd_token.to_uppercase().as_str() {
        "LINE" | "L" => {
            // LINE [start_x,start_y] [end_x,end_y]
            let (rest, first) = opt(parse_point)(rest)?;
            let (rest, second) = if first.is_some() {
                let (rest, _) = space0.parse(rest)?;
                opt(parse_point)(rest)?
            } else {
                (rest, None)
            };
            Ok((rest, ParsedCommand::Line(LineArgs {
                start: first,
                end: second,
            })))
        }
        "CIRCLE" | "C" => {
            // CIRCLE [center_x,center_y] [radius]
            let (rest, center) = opt(parse_point)(rest)?;
            let (rest, radius) = if center.is_some() {
                let (rest, _) = space0.parse(rest)?;
                let (rest, r) = opt(float).parse(rest)?;
                (rest, r.map(|v| v as f64))
            } else {
                (rest, None)
            };
            Ok((rest, ParsedCommand::Circle(CircleArgs {
                center,
                radius,
            })))
        }
        "ARC" | "A" => {
            // ARC [center_x,center_y] [radius] [start_angle] [end_angle]
            // NOTE: Arc angles should be validated — if start_angle >= end_angle,
            // the ArcCommand should return an error or treat as a 360° sweep.
            let (rest, center) = opt(parse_point)(rest)?;
            let (rest, radius) = if center.is_some() {
                let (rest, _) = space0.parse(rest)?;
                let (rest, r) = opt(float).parse(rest)?;
                (rest, r.map(|v| v as f64))
            } else {
                (rest, None)
            };
            let (rest, start_angle) = if radius.is_some() {
                let (rest, _) = space0.parse(rest)?;
                let (rest, a) = opt(float).parse(rest)?;
                (rest, a.map(|v| v as f64))
            } else {
                (rest, None)
            };
            let (rest, end_angle) = if start_angle.is_some() {
                let (rest, _) = space0.parse(rest)?;
                let (rest, a) = opt(float).parse(rest)?;
                (rest, a.map(|v| v as f64))
            } else {
                (rest, None)
            };
            Ok((rest, ParsedCommand::Arc(ArcArgs {
                center,
                radius,
                start_angle,
                end_angle,
            })))
        }
        "PLINE" | "PL" => {
            // PLINE x1,y1 x2,y2 ... [C]
            // Collect points until no more valid points or C/Close token
            //
            // NOTE: Close token "C" must be followed by whitespace or
            // end-of-input to avoid false-matching coordinate text like
            // "C10,20" (which should parse as a vertex, not a close).
            let mut vertices = Vec::new();
            let mut rest = rest;

            loop {
                let (r, _) = space0.parse(rest).unwrap_or((rest, ""));

                // Check for close token followed by whitespace or EOF.
                // tag_no_case("C").then(space0) would succeed on "C10,20"
                // because space0 matches zero spaces, so we also check
                // that the next char (if any) is not alphanumeric.
                if let Ok((after_c, _)) = tag_no_case::<_, _, nom::error::Error<_>>("C")(r) {
                    let next_is_end_or_ws = after_c.is_empty()
                        || after_c.chars().next().map(|c| c.is_ascii_whitespace()).unwrap_or(false);
                    if next_is_end_or_ws {
                        return Ok((after_c, ParsedCommand::Polyline(PolylineArgs {
                            vertices,
                            closed: true,
                        })));
                    }
                }

                match parse_point(r) {
                    Ok((r, pt)) => {
                        vertices.push(pt);
                        rest = r;
                    }
                    Err(_) => break,
                }
            }

            if vertices.is_empty() {
                return Err(nom::Err::Error(nom::error::Error::new(
                    rest,
                    nom::error::ErrorKind::Fail,
                )));
            }

            Ok((rest, ParsedCommand::Polyline(PolylineArgs {
                vertices,
                closed: false,
            })))
        }
        _ => unreachable!(), // Guaranteed by alt() above
    }
}
```

### 6.3 LINE Command Implementation

```rust
// src/commands/line_cmd.rs

/// The LINE command uses a **buffer-then-commit** design:
///
/// 1. Points are accumulated in `pending_points`.
/// 2. On `Complete`, all buffered segments are spawned into the ECS.
/// 3. On `Cancel`, the buffer is dropped (nothing spawned → no cleanup needed).
///
/// This avoids the problem of spawning entities eagerly and then having to
/// track which entities to despawn on cancel.
pub struct LineCommand {
    pending_points: Vec<Point2D>, // Accumulated vertices (not yet in ECS)
    preview_entity: Option<PreviewEntity>, // Rubber-band line preview
}

impl LineCommand {
    pub fn new() -> Self {
        Self {
            pending_points: Vec::new(),
            preview_entity: None,
        }
    }
}

impl Command for LineCommand {
    fn name(&self) -> &'static str { "LINE" }

    fn prompt(&self) -> String {
        if self.pending_points.is_empty() {
            "Specify first point:".to_string()
        } else {
            "Specify next point or [Undo]:".to_string()
        }
    }

    fn steps_remaining(&self) -> usize {
        // Returns 0 once two points are accumulated, allowing inline
        // commands like "LINE 0,0 100,100" to auto-commit.
        if self.pending_points.len() < 2 { 2 - self.pending_points.len() } else { 0 }
    }

    fn on_input(&mut self, input: CommandInput, world: &mut World) -> CommandResult {
        match input {
            CommandInput::Point(p) => {
                self.pending_points.push(p);
                // Check if we have enough points to auto-complete
                // (LINE with just two points is a single segment)
                CommandResult::Continue
            }
            CommandInput::Text(ref t) if t.eq_ignore_ascii_case("U") => {
                // Undo last point
                self.pending_points.pop();
                CommandResult::Continue
            }
            CommandInput::Text(ref t) if t.eq_ignore_ascii_case("C") && self.pending_points.len() >= 3 => {
                // Close polyline — handled by PLINE, ignore here
                CommandResult::Continue
            }
            CommandInput::Confirm if self.pending_points.len() >= 2 => {
                // Commit all buffered geometry to the ECS
                for window in self.pending_points.windows(2) {
                    // NOTE: Position is intentionally omitted in v0.1.0 since
                    // LineData stores absolute coordinates. Add Position when
                    // transform support lands (v0.2.0+).
                    world.spawn((
                        LineData {
                            start: window[0],
                            end: window[1],
                            color: Color::WHITE,
                            width: 1.0,
                        },
                        Renderable,
                    ));
                }
                CommandResult::Complete
            }
            CommandInput::Cancel => {
                self.on_cancel(world);
                CommandResult::Cancelled
            }
            _ => CommandResult::Error("Invalid input. Specify a point.".to_string()),
        }
    }

    fn preview(&self) -> Vec<PreviewEntity> {
        // NOTE: Rubber-band preview is not implemented in v0.1.0.
        // pending_points should be converted to PreviewEntity segments
        // here once the EntityRenderer has a preview draw path.
        vec![]
    }

    fn on_cancel(&mut self, _world: &mut World) {
        // Buffer is simply dropped — nothing was spawned.
        self.pending_points.clear();
        self.preview_entity = None;
    }
}
```

## 7. Rendering Pipeline

### 7.1 Render Pass Order

Each frame executes the following render passes in order:

1. **Clear Pass** — clear color from `CameraState.clear_color`
2. **Grid Pass** — draw major/minor grid lines and X/Y axes
3. **Entity Pass** — draw all entities with `Renderable` component
4. **UI Overlay Pass** — egui panels, status bar, command line (always on top)

### 7.2 Orthographic Camera

NOTE: OrthographicCamera duplicates CameraState (§5.3). In v0.2.0+, consolidate into a single camera type. For v0.1.0 both are kept separate — CameraState is the ECS resource, OrthographicCamera is the render-side projection helper.

```rust
// src/render/camera.rs
pub struct OrthographicCamera {
    pub target: Point2D,
    pub zoom: f64,
    pub viewport_width: f32,
    pub viewport_height: f32,
}

impl OrthographicCamera {
    /// Compute the view-projection matrix for wgpu.
    /// 
    /// World Y+ is up. Screen Y+ is down. We flip in projection.
    ///
    /// ## Rationale for `nalgebra::Orthographic3`
    /// This type is designed for 3D orthographic projection but is perfectly
    /// suitable for 2D when z=0. We use it instead of manual matrix construction
    /// because it handles near/far clipping and coordinate conventions correctly.
    ///
    /// NOTE: The orthographic bounds are computed relative to `self.target`,
    /// so the projection itself encodes the camera position. No separate view
    /// translation is needed — applying one would double-translate and break pan.
    pub fn build_view_projection_matrix(&self) -> nalgebra::Matrix4<f32> {
        let z = self.zoom.max(0.0001);
        let half_w = (self.viewport_width as f64) / (2.0 * z);
        let half_h = (self.viewport_height as f64) / (2.0 * z);

        let left = (self.target.x - half_w) as f32;
        let right = (self.target.x + half_w) as f32;
        let bottom = (self.target.y - half_h) as f32;
        let top = (self.target.y + half_h) as f32;

        let proj = nalgebra::Orthographic3::new(left, right, top, bottom, -1.0, 1.0);
        proj.as_matrix().clone()
    }
}
```

### 7.3 Grid Renderer

The grid is rendered as a single vertex-buffered line list, regenerated only when camera zoom/position changes significantly (≥10% shift).

**Strategy:**
- Compute visible world bounds from camera
- Generate line vertices for major and minor grid lines within bounds + margin
- Use a single `LineList` primitive with vertex colors
- Axis lines (X=0, Y=0) use distinct color

**Vertex format:**
```rust
#[repr(C)]
#[derive(Copy, Clone, Debug, bytemuck::Pod, bytemuck::Zeroable)]
struct GridVertex {
    position: [f32; 2],
    color: [f32; 4],
}
```

**WGSL Vertex Shader:**
```wgsl
// src/render/shaders/grid.wgsl
struct VertexInput {
    @location(0) position: vec2<f32>,
    @location(1) color: vec4<f32>,
};

struct VertexOutput {
    @builtin(position) clip_position: vec4<f32>,
    @location(0) color: vec4<f32>,
};

@group(0) @binding(0)
var<uniform> view_proj: mat4x4<f32>;

@vertex
fn vs_main(in: VertexInput) -> VertexOutput {
    var out: VertexOutput;
    out.clip_position = view_proj * vec4<f32>(in.position, 0.0, 1.0);
    out.color = in.color;
    return out;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    return in.color;
}
```

### 7.4 Entity Renderer

**Line entities** are rendered as `LineList` primitives. Each `LineData` component generates 2 vertices.

**Circle entities** are rendered as line-strip approximations (64 segments for now, configurable by radius). Arcs use proportional segment count based on sweep angle.

**Polyline entities** are rendered as `LineStrip` (open) or `LineList` (closed, with closing segment).

**Batching strategy (v0.1.0):** All entities of the same type are batched into a single combined vertex buffer and drawn with one draw call per entity type per frame. For example, all `LineData` entities are packed into one `LineList` draw call. This is essential for meeting the 10,000-entity performance target. Optimization deferred to v0.2.0+ (instancing, indirect draw, culling).

**Entity vertex format (all entity types):**
```rust
#[repr(C)]
#[derive(Copy, Clone, bytemuck::Pod, bytemuck::Zeroable)]
struct EntityVertex {
    position: [f32; 2],
    color: [f32; 4],
}
```

NOTE: Arc angles are stored as degrees in ArcData but must be converted to radians (angle * PI / 180.0) before GPU buffer upload since WGSL trigonometric functions use radians.

**Uniform buffer layout (shared across all entity shaders):**
```wgsl
// src/render/shaders/shared.wgsl
struct CameraUniform {
    view_proj: mat4x4<f32>,
};
@group(0) @binding(0)
var<uniform> camera: CameraUniform;
```

```rust
// src/input/mod.rs
pub struct InputMapper {
    pub state: InputState,
    pub last_mouse_screen: (f32, f32),
}

impl InputMapper {
    /// Translate winit event to app action.
    pub fn handle_event(&mut self, event: &winit::event::WindowEvent, camera: &CameraState) -> Vec<InputAction> {
        use winit::event::WindowEvent::*;
        // NOTE: Vec::new() allocates on every event (including mouse moves at 60fps).
        // Consider `smallvec::SmallVec<[InputAction; 4]>` or a reusable
        // `Vec::with_capacity(4)` + `clear()` pattern for v0.2.0+. For v0.1.0 the
        // single-alloc-per-event overhead is acceptable.
        let mut actions = Vec::new();

        match event {
            CursorMoved { position, .. } => {
                // NOTE: Verify position field type is PhysicalPosition<f64> in winit 0.30.
                self.state.mouse_screen = (position.x as f32, position.y as f32);
                self.state.mouse_world = camera.screen_to_world(self.state.mouse_screen);
                actions.push(InputAction::MouseMoved(self.state.mouse_world));
            }
            MouseInput { state: winit::event::ElementState::Pressed, button, .. } => {
                match button {
                    winit::event::MouseButton::Left => {
                        self.state.left_down = true;
                        actions.push(InputAction::Click(self.state.mouse_world));
                    }
                    winit::event::MouseButton::Middle => {
                        self.state.middle_down = true;
                        self.last_mouse_screen = self.state.mouse_screen;
                    }
                    winit::event::MouseButton::Right => {
                        self.state.right_down = true;
                        // Right-click reserved for CAD context menu (v0.2.0+).
                        // In v0.1.0, right-click is a no-op placeholder.
                    }
                    _ => {}
                }
            }
            MouseInput { state: winit::event::ElementState::Released, button, .. } => {
                match button {
                    winit::event::MouseButton::Left => self.state.left_down = false,
                    winit::event::MouseButton::Middle => self.state.middle_down = false,
                    winit::event::MouseButton::Right => self.state.right_down = false,
                    _ => {}
                }
            }
            MouseWheel { delta, .. } => {
                let dy = match delta {
                    winit::event::MouseScrollDelta::LineDelta(_, y) => *y as f64,
                    winit::event::MouseScrollDelta::PixelDelta(pos) => pos.y as f64 / 100.0,
                };
                actions.push(InputAction::Zoom(dy, self.state.mouse_world));
            }
            KeyboardInput { event, .. } => {
                if event.state == winit::event::ElementState::Pressed {
                    match event.physical_key {
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::Escape) => {
                            actions.push(InputAction::Cancel);
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::Enter) => {
                            actions.push(InputAction::Confirm);
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ShiftLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ShiftRight) => {
                            self.state.shift = true;
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ControlLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ControlRight) => {
                            self.state.ctrl = true;
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::AltLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::AltRight) => {
                            self.state.alt = true;
                        }
                        _ => {
                            if let winit::keyboard::Key::Character(c) = &event.logical_key {
                                if c.len() == 1 {
                                    actions.push(InputAction::Text(c.chars().next().unwrap()));
                                }
                            }
                        }
                    }
                } else {
                    match event.physical_key {
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ShiftLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ShiftRight) => {
                            self.state.shift = false;
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ControlLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::ControlRight) => {
                            self.state.ctrl = false;
                        }
                        winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::AltLeft)
                        | winit::keyboard::PhysicalKey::Code(winit::keyboard::KeyCode::AltRight) => {
                            self.state.alt = false;
                        }
                        _ => {}
                    }
                }
            }
            _ => {}
        }

        // NOTE: The `KeyboardInput` event's `event` field is a `KeyEvent` struct.
        // The fields `state`, `physical_key`, and `logical_key` should be verified
        // against the winit 0.30 release to ensure field names and types are correct.

        // Pan handling (middle-drag)
        if self.state.middle_down {
            let dx = self.state.mouse_screen.0 - self.last_mouse_screen.0;
            let dy = self.state.mouse_screen.1 - self.last_mouse_screen.1;
            if dx != 0.0 || dy != 0.0 {
                actions.push(InputAction::Pan(dx as f64, dy as f64));
            }
            self.last_mouse_screen = self.state.mouse_screen;
        }

        actions
    }
}

pub enum InputAction {
    MouseMoved(Point2D),
    Click(Point2D),
    Pan(f64, f64),     // dx, dy in screen pixels
    Zoom(f64, Point2D), // delta, pivot point in world space
    Cancel,
    Confirm,
    #[allow(dead_code)]
    Text(char),
    #[allow(dead_code)]
    CommandText(String), // Full command line submission
}

// NOTE: InputAction::Text(char) emits individual keystroke characters
// for the command system. This operates alongside egui's text input
// (text_edit_singleline in the command line UI). The winit keyboard
// handler routes text to InputAction::Text when no active command
// expects it; when the command line has focus, egui swallows the
// event first and the keystroke never reaches InputMapper. See §10
// window_event for the egui-first event priority ordering.
//
// NOTE: InputAction::CommandText(String) is defined but never produced
// by handle_event. The egui command line captures Enter and dispatches
// via ForgeApp::dispatch_command_text directly in the window_event
// handler. CommandText is reserved for future direct keyboard command
// input that bypasses the egui text field.
```

```rust
// src/input/camera_control.rs
pub fn apply_camera_action(camera: &mut CameraState, action: &InputAction) {
    match action {
        InputAction::Pan(dx, dy) => {
            // Defensive: zoom is clamped in the Zoom handler, but if this
            // function is ever called before zoom is initialised, prevent
            // division by zero by flooring to a minimum positive value.
            let z = camera.zoom.max(0.0001);

            // Convert screen pixels to world units at current zoom
            let world_dx = -dx / z;
            let world_dy = dy / z; // screen Y is inverted
            camera.target.x += world_dx;
            camera.target.y += world_dy;
        }
        InputAction::Zoom(delta, pivot) => {
            let zoom_factor = 1.1f64.powf(*delta);
            let old_zoom = camera.zoom;
            camera.zoom = (camera.zoom * zoom_factor).clamp(0.0001, 100000.0);

            // Zoom towards mouse pointer (world pivot stays under cursor)
            let zoom_ratio = old_zoom / camera.zoom;
            camera.target.x = pivot.x + (camera.target.x - pivot.x) * zoom_ratio;
            camera.target.y = pivot.y + (camera.target.y - pivot.y) * zoom_ratio;
        }
        _ => {}
    }
}
```

```rust
                // NOTE: Egui's text_edit_singleline retains focus on Enter,
                // so lost_focus() may not trigger. Check key_pressed(Enter)
                // independently as a fallback.

                    let text = cmd_state.buffer.trim().to_string();

                        cmd_state.history.push(text.clone());
                        cmd_state.pending_dispatch = Some(text);
                        cmd_state.buffer.clear();
                    }
                }
                if response.has_focus() && ui.input(|i| i.key_pressed(egui::Key::Escape)) {
                    cmd_state.buffer.clear();
                }
            });
        });
```

```rust
// src/main.rs
use std::sync::Arc;
use winit::{
    application::ApplicationHandler,
    event::WindowEvent,
    event_loop::{ActiveEventLoop, EventLoop},
    window::{Window, WindowId},
};

fn main() {
    // Initialise structured logging
    tracing_subscriber::fmt()
        .with_env_filter(
            tracing_subscriber::EnvFilter::try_from_default_env()
                .unwrap_or_else(|_| "forge=info,wgpu=warn".into()),
        )
        .try_init()
        .ok();  // Silently ignore if already initialized (e.g., in test contexts).

    let event_loop = EventLoop::new().unwrap();
    let mut app = ForgeAppHandler::new();
    // winit 0.30: run_app returns Result<(), EventLoopError>
    // For v0.1.0 we exit on event loop failure. Graceful recovery deferred to v0.2.0+.
    event_loop.run_app(&mut app).expect("Event loop failed");
}

pub struct ForgeAppHandler {
    state: Option<ForgeState>,
}

impl ForgeAppHandler {
    pub fn new() -> Self {
        Self { state: None }
    }
}

pub struct ForgeState {
    window: Arc<Window>,
    app: ForgeApp,
}

impl ApplicationHandler for ForgeAppHandler {
    fn resumed(&mut self, event_loop: &ActiveEventLoop) {
        // Drop any existing state before recreating (resumed can fire
        // multiple times on macOS when the app is reactivated after
        // being hidden, which would leak the previous GPU resources).
        if self.state.is_some() {
            tracing::debug!("resumed called with existing state — dropping prior window/GPU resources");
            self.state = None;
        }

        let window_attributes = winit::window::WindowAttributes::default()
            .with_title("Forge v0.1.0")
            .with_inner_size(winit::dpi::LogicalSize::new(1280, 720));

        let window = match event_loop.create_window(window_attributes) {
            Ok(w) => Arc::new(w),
            Err(e) => {
                tracing::error!("Failed to create window: {}", e);
                event_loop.exit();
                return;
            }
        };
        let app = pollster::block_on(ForgeApp::new(window.clone()));
        // NOTE: Synchronous GPU init blocks the event loop. If startup exceeds 2s target, consider async init with loading screen (v0.2.0+).
        // NOTE: GPU resource recreation on macOS resume causes brief black frame flicker.
        // Optimize in v0.2.0+ by preserving GPU resources and reconfiguring only the surface.

        self.state = Some(ForgeState { window, app });
    }

    fn window_event(&mut self, event_loop: &ActiveEventLoop, _window_id: WindowId, event: WindowEvent) {
        if let Some(state) = &mut self.state {
            // Handle lifecycle events before egui/viewport processing
            match &event {
                WindowEvent::CloseRequested => {
                    tracing::info!("Window close requested, shutting down");
                    event_loop.exit();
                    return;
                }
                WindowEvent::Destroyed => {
                    tracing::info!("Window destroyed, exiting event loop");
                    self.state = None;
                    event_loop.exit();
                    return;
                }
                WindowEvent::Resized(new_size) => {
                    // Update wgpu surface config for new physical size
                    state.app.render_state.resize(*new_size);
                    // Update camera viewport dimensions for coordinate transforms
                    state.app.resources.camera.viewport_size =
                        (new_size.width, new_size.height);
                    // Force grid regeneration on next render
                    // (resize changes visible bounds without changing target/zoom)
                    state.app.render_state.grid_renderer.invalidate();
                    state.window.request_redraw();
                    // Surface is reconfigured and camera updated; fall through
                    // to egui event processing for panel layout updates.
                }
                WindowEvent::ScaleFactorChanged { scale_factor, .. } => {
                    // On HiDPI/Retina displays, egui must be told about
                    // the new scale factor so its text and panels render
                    // at the correct size.
                    state.app.ui_system.set_scale_factor(*scale_factor as f32);
                    state.window.request_redraw();
                    return;
                }
                _ => {}
            }

            // Dispatch any pending command text from the UI command line
            if let Some(text) = state.app.command_state.pending_dispatch.take() {
                state.app.dispatch_command_text(&text);
            }

            // 1. Let egui consume events first (UI priority)
            //
            // NOTE: The exact signature of `egui_winit::State::on_window_event` in
            // egui-winit 0.34 with winit 0.30 should be verified against the actual
            // release. The return type may be `egui_winit::EventResponse` (with `.consumed`
            // field), a `bool`, or some other type. Adjust the `.consumed` access as needed.
            let egui_consumed = state.app.ui_system.egui_state.on_window_event(
                &state.app.ui_system.egui_ctx,
                &event,
            ).consumed;

            if egui_consumed {
                state.window.request_redraw();
                return;
            }

            // 2. Map remaining events to input actions
            let actions = state.app.input_mapper.handle_event(&event, &state.app.resources.camera);

            for action in actions {
                match action {
                    InputAction::Click(point) => {
                        if let Some(ref mut cmd) = state.app.command_state.active {
                            let result = cmd.on_input(CommandInput::Point(point), &mut state.app.world);
                            match result {
                                CommandResult::Complete => {
                                    state.app.command_state.active = None;
                                    state.app.command_state.last_error = None;
                                }
                                CommandResult::Cancelled => {
                                    state.app.command_state.active = None;
                                    state.app.command_state.last_error = None;
                                }
                                CommandResult::Error(msg) => {
                                    tracing::warn!("Command error: {}", msg);
                                    state.app.command_state.last_error = Some(msg);
                                }
                                _ => {}
                            }
                        }
                    }
                    InputAction::Pan(_, _) | InputAction::Zoom(_, _) => {
                        apply_camera_action(&mut state.app.resources.camera, &action);
                    }
                    InputAction::Cancel => {
                        if let Some(ref mut cmd) = state.app.command_state.active {
                            cmd.on_cancel(&mut state.app.world);
                        }
                        state.app.command_state.active = None;
                    }
                    InputAction::CommandText(text) => {
                        state.app.dispatch_command_text(&text);
                    }
                    InputAction::MouseMoved(_) => {
                        // Trigger preview update if active command has preview geometry
                        if state.app.command_state.active.is_some() {
                            state.window.request_redraw();
                        }
                    }
                    // InputAction::Text(char) — deferred to v0.2.0+ command layer.
                    // Individual keystrokes when no egui widget has focus will be
                    // routed to the command system in a future revision.
                    _ => {}
                }
            }

            state.window.request_redraw();
        }
    }

    fn about_to_wait(&mut self, _event_loop: &ActiveEventLoop) {
        if let Some(state) = &self.state {
            // Continuous rendering via request_redraw on every idle.
            // NOTE: This does not check for window occlusion (minimized/hidden).
            // On macOS and Windows, this may waste GPU cycles when the window
            // is not visible. Track WindowEvent::Occluded(bool) and skip
            // redraw when occluded. Deferred to v0.2.0+.
            state.window.request_redraw();
        }
    }
}
```

```rust
// src/app.rs
use std::sync::Arc;

pub struct ForgeApp {
    pub world: hecs::World,
    pub resources: ResourceBank,
    pub command_state: CommandState,
    pub render_state: RenderState,
    pub ui_system: UiSystem,
    pub input_mapper: InputMapper,
}

pub struct ResourceBank {
    pub camera: CameraState,
    pub grid: GridConfig,
}

impl ForgeApp {
    pub async fn new(window: Arc<winit::window::Window>) -> Self {
        let world = hecs::World::new();
        let resources = ResourceBank {
            camera: CameraState {
                target: Point2D::new(0.0, 0.0),
                zoom: 1.0,
                viewport_size: (1280, 720),
                clear_color: Color::from_hex(0x2B2B2B),
            },
            grid: GridConfig {
                visible: true,
                major_spacing: 100.0,
                minor_spacing: 10.0,
                major_color: Color::from_hex(0x666666),
                minor_color: Color::from_hex(0x444444),
                axis_color: Color::from_hex(0x888888),
            },
        };

        let render_state = RenderState::new(window.clone())
            .await
            .unwrap_or_else(|e| panic!("Failed to initialise GPU render state: {}", e));
        let ui_system = UiSystem::new(&window);
        let input_mapper = InputMapper {
            state: InputState::default(),
            last_mouse_screen: (0.0, 0.0), // NOTE: Initial pan will jump if middle-click before mouse move (v0.2.0+)
        };

        Self {
            world,
            resources,
            command_state: CommandState::default(),
            render_state,
            ui_system,
            input_mapper,
        }
    }

    pub fn render(&mut self, window: &winit::window::Window) {
        let output = match self.render_state.surface.get_current_texture() {
            Ok(frame) => frame,
            Err(wgpu::SurfaceError::Lost) => {
                tracing::warn!("Surface lost, reconfiguring and requesting redraw");
                self.render_state.resize(window.inner_size());
                self.render_state.grid_renderer.invalidate();
                window.request_redraw();
                return;
            }
            Err(wgpu::SurfaceError::Outdated) => {
                // Frame outdated: skip this frame (swap chain reconfigured).
                return;
            }
            Err(wgpu::SurfaceError::Timeout) => {
                // Timeout acquiring frame: skip.
                return;
            }
            Err(err) => {
                tracing::error!("Surface error: {:?}", err);
                return;
            }
        };

        let view = output.texture.create_view(&wgpu::TextureViewDescriptor::default());

        let mut encoder = self.render_state.device.create_command_encoder(&wgpu::CommandEncoderDescriptor {
            label: Some("Render Encoder"),
        });

        // Update camera uniform
        let vp_matrix = self.resources.camera.view_proj_matrix();
        // Matrix4<f32> implements AsRef<[f32; 16]>, so .as_ref() yields a &[f32; 16] slice.
        self.render_state.queue.write_buffer(
            &self.render_state.camera_buffer,
            0,
            bytemuck::cast_slice(vp_matrix.as_ref()),
        );

        // 1. Grid pass
        if self.resources.grid.visible {
            self.render_state.grid_renderer.render(&mut encoder, &view, &self.resources.camera, &self.resources.grid, &self.render_state.camera_bind_group);
        }

        // 2. Entity pass
        self.render_state.entity_renderer.render(&mut encoder, &view, &self.world, &self.render_state.camera_bind_group);

        // 3. UI pass (egui)
        let screen_descriptor = egui_wgpu::ScreenDescriptor {
            size_in_pixels: self.resources.camera.viewport_size,
            pixels_per_point: window.scale_factor() as f32,
        };
        let primitives = self.ui_system.run(window, self);
        // NOTE: The exact signature of `egui_wgpu::Renderer::update_buffers` in
        // egui-wgpu 0.34 with wgpu 0.29 should be verified against the actual
        // release. The method may have been split into `update_textures` and
        // `update_buffers` separately, or renamed to `update_textures_and_buffers`,
        // or accept `&egui::TexturesDelta` separately. Adjust the call signature
        // based on the egui-wgpu 0.34.0 changelog.
        self.render_state.egui_renderer.update_buffers(
            &self.render_state.device,
            &self.render_state.queue,
            &mut encoder,
            &primitives,
            &screen_descriptor,
        );
        {
            let mut render_pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
                label: Some("UI Render Pass"),
                color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                    view: &view,
                    resolve_target: None,
                    ops: wgpu::Operations {
                        load: wgpu::LoadOp::Load,
                        store: wgpu::StoreOp::Store,
                    },
                })],
                depth_stencil_attachment: None,
                timestamp_writes: None,
                occlusion_query_set: None,
            });
            self.render_state.egui_renderer.render(
                &mut render_pass,
                &primitives,
                &screen_descriptor,
            );
        }

        self.render_state.queue.submit(std::iter::once(encoder.finish()));
        output.present();
    }

    /// Dispatch text from the UI command line to the command system.
    ///
    /// The text buffer is parsed and either:
    /// - Starts a new command (e.g. "LINE 0,0 100,100")
    /// - Passes text to the active command (e.g. coordinates, distance)
    pub fn dispatch_command_text(&mut self, text: &str) {
        // If there is an active command, feed the text as a CommandInput
        if let Some(ref mut cmd) = self.command_state.active {
            let trimmed = text.trim();

            // Compute input first to avoid overlapping mutable borrows
            let input = if let Ok((_, point)) = commands::parser::parse_point(trimmed) {
                Some(CommandInput::Point(point))
            } else {
                Some(CommandInput::Text(trimmed.to_string()))
            };

            if let Some(input) = input {
                let result = cmd.on_input(input, &mut self.world);
                match result {
                    CommandResult::Complete => {
                        self.command_state.active = None;
                        self.command_state.last_error = None;
                    }
                    CommandResult::Cancelled => {
                        self.command_state.active = None;
                        self.command_state.last_error = None;
                    }
                    CommandResult::Error(msg) => {
                        tracing::warn!("Command error: {}", msg);
                        self.command_state.last_error = Some(msg);
                    }
                    _ => {}
                }
            }
            return;
        }

        // No active command: parse the full text as a command invocation
        match commands::parser::parse_command(text.trim()) {
            Ok((remaining, parsed)) => {
                // If there's leftover text after parsing, that's a warning
                if !remaining.trim().is_empty() {
                    tracing::warn!("Unrecognised trailing input after command: {:?}", remaining);
                }

                // Dispatch based on the parsed command type
                let cmd: Box<dyn Command> = match parsed {
                    commands::parser::ParsedCommand::Line(args) => {
                        let mut line_cmd = Box::new(commands::line_cmd::LineCommand::new());
                        // If points were provided inline, feed them
                        if let Some(start) = args.start {
                            line_cmd.on_input(CommandInput::Point(start), &mut self.world);
                        }
                        if let Some(end) = args.end {
                            line_cmd.on_input(CommandInput::Point(end), &mut self.world);
                        }
                        line_cmd
                    }
                    commands::parser::ParsedCommand::Circle(args) => {
                        self.command_state.last_error = Some("CIRCLE command not yet implemented (v0.2.0)".to_string());
                        return;
                    }
                    commands::parser::ParsedCommand::Arc(args) => {
                        self.command_state.last_error = Some("ARC command not yet implemented (v0.2.0)".to_string());
                        return;
                    }
                    commands::parser::ParsedCommand::Polyline(args) => {
                        self.command_state.last_error = Some("PLINE command not yet implemented (v0.2.0)".to_string());
                        return;
                    }
                };

                // If command already has enough input, finalise immediately
                // by sending a Confirm event to trigger the commit logic.
                if cmd.steps_remaining() == 0 {
                    let result = cmd.on_input(CommandInput::Confirm, &mut self.world);
                    match result {
                        CommandResult::Complete => {
                            self.command_state.last_error = None;
                        }
                        CommandResult::Cancelled => {
                            self.command_state.last_error = None;
                        }
                        CommandResult::Error(msg) => {
                            tracing::warn!("Command error: {}", msg);
                            self.command_state.last_error = Some(msg);
                        }
                        _ => self.command_state.active = Some(cmd),
                    }
                } else {
                    self.command_state.active = Some(cmd);
                }
            }
            Err(nom::Err::Error(e)) | Err(nom::Err::Failure(e)) => {
                tracing::warn!("Unrecognised command: {} ({:?})", text.trim(), e);
                self.command_state.last_error = Some(format!("Unrecognised command: {}", text.trim()));
            }
            // Incomplete is unreachable with complete parsers; handled for forward-compat
            // if switching to streaming parsers in v0.2.0+.
            Err(nom::Err::Incomplete(_)) => {}
        }
    }

    /// Safely handle GPU device loss by recreating the render state.
    /// Called from the device loss callback (future).
    #[allow(dead_code)]
    pub async fn recover_device(&mut self, window: Arc<winit::window::Window>) {
        tracing::warn!("Attempting GPU device recovery...");
        match RenderState::new(window).await {
            Ok(new_state) => {
                // SAFETY: We replace the entire render state atomically.
                // Old GPU resources are dropped (GPU-side cleanup handled by
                // wgpu when the old Device is dropped).
                self.render_state = new_state;
                tracing::info!("GPU device recovery successful");
            }
            Err(e) => {
                tracing::error!("GPU device recovery failed: {:?}", e);
                // In production, surface a dialog to the user. For v0.1.0,
                // the error is logged and the app will try again next frame.
            }
        }
    }
}
```

#### ForgeError Definition

```rust
// src/util/error.rs
use thiserror::Error;

/// Application-level error type for Forge.
///
/// # Error Handling Strategy (v0.1.0)
/// In v0.1.0, most fallible operations use `.expect()` or `.unwrap()` for
/// simplicity during early development (startup, GPU init, etc.). Proper
/// error recovery with user-facing messages is deferred to v0.2.0+.
/// This enum exists to define the error surface and will be wired into
/// the command system and render pipeline in the next iteration.
#[derive(Error, Debug)]
pub enum ForgeError {
    #[error("GPU error: {0}")]
    Gpu(String),
    #[error("Surface error: {0}")]
    Surface(String),
    #[error("Command error: {0}")]
    Command(String), // Reserved: command errors surface via CommandState::last_error in v0.1.0
    #[error("Parse error: {0}")]
    Parse(String), // Currently unused — nom errors surface through CommandState::last_error.
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
}

impl From<wgpu::Error> for ForgeError {
    fn from(e: wgpu::Error) -> Self {
        ForgeError::Gpu(e.to_string())
    }
}

impl From<wgpu::SurfaceError> for ForgeError {
    fn from(e: wgpu::SurfaceError) -> Self {
        ForgeError::Surface(e.to_string())
    }
}
```

```rust
// src/util/color.rs
/// RGBA color stored as f32 values in [0, 1] range.
#[derive(Debug, Clone, Copy, PartialEq, Default, bytemuck::Pod, bytemuck::Zeroable)]
#[repr(C)]
pub struct Color {
    pub r: f32,
    pub g: f32,
    pub b: f32,
    pub a: f32,
}

impl Color {
    /// Create from 24-bit hex value (0xRRGGBB). High byte is ignored; alpha is always 1.0. Use From<[f32; 4]> for custom alpha.
    pub const fn from_hex(hex: u32) -> Self {
        Self {
            r: (((hex >> 16) & 0xFF) as f32) / 255.0f32,
            g: (((hex >> 8) & 0xFF) as f32) / 255.0f32,
            b: ((hex & 0xFF) as f32) / 255.0f32,
            a: 1.0,
        }
    }

    pub const WHITE: Self = Self::from_hex(0xFFFFFF);
    pub const BLACK: Self = Self::from_hex(0x000000);
    pub const GRAY_DARK: Self = Self::from_hex(0x444444);
    pub const GRAY_MEDIUM: Self = Self::from_hex(0x666666);
    pub const GRAY_LIGHT: Self = Self::from_hex(0x888888);
}
```

## 14. Risk Assessment

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| **wgpu backend fails on older GPU** | Medium | High | Test on minimum spec; document Vulkan/Metal/DX12 requirements |
| **hecs archetype fragmentation** | Low | Medium | Monitor entity spawn patterns; batch spawns when possible |
| **f64→f32 precision loss in large coordinates** | Medium | High | Use world-space partitioning; warn on coordinates >1e6 |
| **egui event consumption conflicts** | Medium | Medium | Explicit event priority: UI → commands → camera; log unconsumed events |
| **Cross-platform window resize bugs** | Medium | Low | Handle `Resized` event immediately; regenerate surface config |
| **Command parser ambiguity** | Low | Medium | Strict grammar; comprehensive parser tests; clear error messages |
| **Grid vertex buffer overflow** | Low | High | Cap grid generation to visible bounds + margin; use index buffers |
