## 1. Scope & Objectives

### 1.1 In Scope
- **Selection system** — single click, window (crossing/enclosing), select-all, deselect
- **GPU picking** — entity ID framebuffer readback for pixel-perfect selection
- **Snapping engine** — 7 snap types with magnetic cursor and visual feedback
- **Spatial indexing** — R-tree for snap queries, window selection, and view culling
- **Modify commands** — ERASE, MOVE, COPY, ROTATE, SCALE, MIRROR, OFFSET
- **Undo/Redo** — delta-based command journal with infinite depth
- **Selection visual feedback** — highlight glow, bounding box grips
- **Command integration** — snaps feed into active draw/modify commands

### 1.2 Out of Scope
- Layer system (v0.3.0)
- Block editing (v0.3.0)
- File I/O (v0.5.0)
- Constraint solving (v0.7.0)
- Multi-select modifier keys (Ctrl+click) — deferred to v0.3.0
- Grip editing (stretch via handles) — deferred to v0.3.0

## 5. Selection System

### 5.1 Selection Model

Selection is represented by a **marker component** `Selected` on entities. The `SelectionManager` maintains a `HashSet<hecs::Entity>` for O(1) membership tests and provides the canonical selection API.

```rust
// src/ecs/components.rs
/// Marker: entity is currently selected.
#[derive(Debug, Clone, Copy, Component)]
pub struct Selected;

/// Selection bounding box — computed on-demand from entity geometry,
/// not stored persistently. Modify commands must update bounding boxes
/// for window select and view culling via the SpatialIndex.
```

```rust
// src/selection/mod.rs
use hecs::World;
use std::collections::HashSet;

pub struct SelectionManager {
    pub selected: HashSet<hecs::Entity>,
    pub primary: Option<hecs::Entity>, // Last selected entity (for property panel)
    pub mode: SelectionMode,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum SelectionMode {
    #[default]
    Replace,    // Click replaces selection
    Add,        // Future: Ctrl+click adds
    Remove,     // Future: Ctrl+click removes
}

impl SelectionManager {
    pub fn select(&mut self, world: &mut World, entity: hecs::Entity) {
        if self.selected.insert(entity) {
            world.insert_one(entity, Selected).ok();
            self.primary = Some(entity);
        }
    }

    pub fn deselect(&mut self, world: &mut World, entity: hecs::Entity) {
        if self.selected.remove(&entity) {
            world.remove_one::<Selected>(entity).ok();
        }
        if self.primary == Some(entity) {
            self.primary = self.selected.iter().next().copied();
        }
    }

    pub fn clear(&mut self, world: &mut World) {
        for &entity in &self.selected {
            world.remove_one::<Selected>(entity).ok();
        }
        self.selected.clear();
        self.primary = None;
    }

    pub fn replace(&mut self, world: &mut World, entity: hecs::Entity) {
        self.clear(world);
        self.select(world, entity);
    }

    pub fn is_empty(&self) -> bool {
        self.selected.is_empty()
    }

    pub fn count(&self) -> usize {
        self.selected.len()
    }
}
```

**Picking WGSL shader:**
```wgsl
// src/render/shaders/picking.wgsl
struct VertexInput {
    @location(0) position: vec2<f32>,
};

struct VertexOutput {
    @builtin(position) clip_position: vec4<f32>,
    @location(0) @interpolate(flat) entity_id: u32,
};

@group(0) @binding(0)
var<uniform> view_proj: mat4x4<f32>;

@vertex
fn vs_main(in: VertexInput, @builtin(instance_index) instance: u32) -> VertexOutput {
    var out: VertexOutput;
    out.clip_position = view_proj * vec4<f32>(in.position, 0.0, 1.0);
    out.entity_id = instance; // Entity index passed via instance_id
    return out;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<u32> {
    return vec4<u32>(in.entity_id, 0u, 0u, 0xFFFFFFFFu);
}
```

**Entity-to-index mapping:**
- The `PickingPass` owns a `Vec<hecs::Entity>` mapping from instance index to entity handle.
- Each frame that requires picking, the mapping is regenerated by querying the ECS world for all `Renderable` entities, ensuring the entity order matches the instance buffer layout.
- `instance_index` in the picking draw call corresponds to the index in this vector.
- On entity spawn/despawn, the mapping is rebuilt on the next picking frame.
- The readback decodes the u32 pixel value back to an entity handle via this mapping: `self.mapping[pixel_u32]`.
- For v0.2.0, simple regeneration is acceptable; optimize with incremental updates in v0.3.0.

### 5.3 Window Selection

When the user left-clicks and drags with **no active command**, a selection rectangle appears:

```rust
// src/selection/window_select.rs
pub enum WindowSelectMode {
    Crossing,   // Green rectangle — selects entities intersecting the rectangle
    Enclosing,  // Blue rectangle — selects entities fully inside the rectangle
}

pub struct WindowSelectState {
    pub start: Point2D,
    pub current: Point2D,
    pub mode: WindowSelectMode,
}

impl WindowSelectState {
    /// Determine mode from drag direction: left-to-right = Enclosing, right-to-left = Crossing
    pub fn mode_from_drag(start_screen: (f32, f32), current_screen: (f32, f32)) -> WindowSelectMode {
        if current_screen.0 >= start_screen.0 {
            WindowSelectMode::Enclosing
        } else {
            WindowSelectMode::Crossing
        }
    }

    /// Query spatial index for entities inside/intersecting the rectangle.
    pub fn query(&self, spatial: &SpatialIndex) -> Vec<hecs::Entity> {
        let rect = BoundingBox2D {
            min: Point2D::new(
                self.start.x.min(self.current.x),
                self.start.y.min(self.current.y),
            ),
            max: Point2D::new(
                self.start.x.max(self.current.x),
                self.start.y.max(self.current.y),
            ),
        };

        match self.mode {
            WindowSelectMode::Enclosing => spatial.enclosed_in(&rect),
            WindowSelectMode::Crossing => spatial.intersecting(&rect),
        }
    }
}
```

**Visual feedback:** The selection rectangle is rendered as a translucent filled quad with a border by the `WindowSelectRenderer` module (`src/render/window_select_renderer.rs`). This module owns a dedicated wgpu pipeline that draws a screen-space quad with configurable fill/border colors. Color indicates mode:
- **Enclosing (blue):** `rgba(0, 120, 255, 0.15)` fill, `rgba(0, 120, 255, 0.8)` border
- **Crossing (green):** `rgba(0, 255, 120, 0.15)` fill, `rgba(0, 255, 120, 0.8)` border

The `WindowSelectRenderer` is rendered in the entity rendering pass order, after grid but before entities, ensuring the rectangle appears below selection highlights.

### 6.3 Candidate Generation

Each entity type implements `SnapCandidate`:

```rust
// src/snap/candidate.rs
pub trait SnapCandidate {
    fn generate_snap_points(&self, world_point: Point2D, snap_types: &[SnapType]) -> Vec<SnapCandidatePoint>;
}

#[derive(Debug, Clone)]
pub struct SnapCandidatePoint {
    pub point: Point2D,
    pub snap_type: SnapType,
    pub distance_world: f64,
}

impl SnapCandidate for LineData {
    fn generate_snap_points(&self, _world_point: Point2D, snap_types: &[SnapType]) -> Vec<SnapCandidatePoint> {
        let mut candidates = Vec::new();
        if snap_types.contains(&SnapType::Endpoint) {
            candidates.push(SnapCandidatePoint {
                point: self.start,
                snap_type: SnapType::Endpoint,
                distance_world: 0.0,
            });
            candidates.push(SnapCandidatePoint {
                point: self.end,
                snap_type: SnapType::Endpoint,
                distance_world: 0.0,
            });
        }
        if snap_types.contains(&SnapType::Midpoint) {
            candidates.push(SnapCandidatePoint {
                point: Point2D::new(
                    (self.start.x + self.end.x) / 2.0,
                    (self.start.y + self.end.y) / 2.0,
                ),
                snap_type: SnapType::Midpoint,
                distance_world: 0.0,
            });
        }
        candidates
    }
}
```

## 7. Spatial Index (rstar)

### 7.1 Index Structure

```rust
// src/spatial/mod.rs
use rstar::{RTree, RTreeObject, PointDistance, AABB};

pub struct SpatialIndex {
    tree: RTree<SpatialEntry>,
    dirty: bool, // Set when entities modified; triggers rebuild
}

#[derive(Debug, Clone, PartialEq)]
pub struct SpatialEntry {
    pub entity: hecs::Entity,
    pub bounds: BoundingBox2D,
}

impl RTreeObject for SpatialEntry {
    type Envelope = AABB<[f64; 2]>;

    fn envelope(&self) -> Self::Envelope {
        AABB::from_corners(
            [self.bounds.min.x, self.bounds.min.y],
            [self.bounds.max.x, self.bounds.max.y],
        )
    }
}

impl PointDistance for SpatialEntry {
    fn distance_2(&self, point: &[f64; 2]) -> f64 {
        self.bounds.envelope().distance_2(point)
    }

    fn contains_point(&self, point: &[f64; 2]) -> bool {
        self.bounds.envelope().contains_point(point)
    }
}

impl SpatialIndex {
    pub fn insert(&mut self, entity: hecs::Entity, bounds: BoundingBox2D) {
        self.tree.insert(SpatialEntry { entity, bounds });
    }

    pub fn remove(&mut self, entity: hecs::Entity) {
        self.tree.remove_with_selection_function(|entry| entry.entity == entity);
    }

    pub fn nearest_neighbor(&self, point: Point2D) -> Option<hecs::Entity> {
        self.tree.nearest_neighbor(&[point.x, point.y])
            .map(|entry| entry.entity)
    }

    pub fn enclosed_in(&self, rect: &BoundingBox2D) -> Vec<hecs::Entity> {
        let envelope = AABB::from_corners(
            [rect.min.x, rect.min.y],
            [rect.max.x, rect.max.y],
        );
        self.tree.locate_in_envelope(&envelope)
            .map(|entry| entry.entity)
            .collect()
    }

    pub fn intersecting(&self, rect: &BoundingBox2D) -> Vec<hecs::Entity> {
        let envelope = AABB::from_corners(
            [rect.min.x, rect.min.y],
            [rect.max.x, rect.max.y],
        );
        self.tree.locate_in_envelope_intersecting(&envelope)
            .map(|entry| entry.entity)
            .collect()
    }

    /// Rebuild from scratch (called after batch operations).
    pub fn rebuild(&mut self, world: &World) {
        let mut entries = Vec::new();
        for (entity, (line,)) in world.query::<(&LineData,)>().iter() {
            entries.push(SpatialEntry {
                entity,
                bounds: line.bounding_box(),
            });
        }
        // ... repeat for CircleData, ArcData, PolylineData
        self.tree = RTree::bulk_load(entries);
        self.dirty = false;
    }
}
```

### 7.2 Integration with Commands

Every command that creates or modifies entities must update the spatial index:

```rust
// In command execution:
spatial.insert(entity, computed_bounds);

// In modify commands (MOVE, ROTATE, etc.):
spatial.remove(entity);
// ... apply transform ...
spatial.insert(entity, new_bounds);
```

For v0.2.0, **lazy rebuild** is acceptable: mark dirty after each command, rebuild before the next snap query if dirty. Optimize with incremental updates in v0.3.0.

## 8. History (Undo/Redo)

### 8.1 Transaction Model

History is a **stack of transactions**. Each transaction contains a list of atomic operations. Undo reverses all operations in the transaction; redo re-applies them.

```rust
// src/history/mod.rs
use std::collections::VecDeque;
use std::collections::HashMap;

pub struct History {
    pub undo_stack: VecDeque<Transaction>,
    pub redo_stack: VecDeque<Transaction>,
    pub max_depth: Option<usize>, // None = unlimited
    entity_map: EntityMapping,  // Track old → new entity handles on undo/redo
}

#[derive(Debug, Clone)]
pub struct Transaction {
    pub label: String, // Human-readable description: "Move 3 entities"
    pub ops: Vec<AtomicOp>,
}

#[derive(Debug, Clone)]
pub enum AtomicOp {
    SpawnLine { entity: hecs::Entity, data: LineData },
    SpawnCircle { entity: hecs::Entity, data: CircleData },
    SpawnArc { entity: hecs::Entity, data: ArcData },
    SpawnPolyline { entity: hecs::Entity, data: PolylineData },
    DespawnLine { entity: hecs::Entity, data: LineData },
    DespawnCircle { entity: hecs::Entity, data: CircleData },
    DespawnArc { entity: hecs::Entity, data: ArcData },
    DespawnPolyline { entity: hecs::Entity, data: PolylineData },
    SetLineData { entity: hecs::Entity, old: LineData, new: LineData },
    SetCircleData { entity: hecs::Entity, old: CircleData, new: CircleData },
    SetArcData { entity: hecs::Entity, old: ArcData, new: ArcData },
    SetPolylineData { entity: hecs::Entity, old: PolylineData, new: PolylineData },
    SetPosition { entity: hecs::Entity, old: Position, new: Position },
}

/// Maps old entity handles to new ones after respawn on undo.
pub struct EntityMapping {
    map: HashMap<hecs::Entity, hecs::Entity>,
}

impl EntityMapping {
    pub fn new() -> Self {
        Self { map: HashMap::new() }
    }

    pub fn map(&self, old: hecs::Entity) -> hecs::Entity {
        self.map.get(&old).copied().unwrap_or(old)
    }

    pub fn record_spawn(&mut self, old: hecs::Entity, new: hecs::Entity) {
        self.map.insert(old, new);
    }

    pub fn clear(&mut self) {
        self.map.clear();
    }
}

impl History {
    pub fn push(&mut self, tx: Transaction) {
        self.redo_stack.clear(); // New action invalidates redo history
        self.undo_stack.push_back(tx);
        if let Some(max) = self.max_depth {
            while self.undo_stack.len() > max {
                self.undo_stack.pop_front();
            }
        }
    }

    /// Undo the top transaction. Returns the label.
    /// After calling, the caller must remap entity handles in
    /// SelectionManager and SpatialIndex using `take_entity_mapping()`.
    pub fn undo(&mut self, world: &mut World) -> Option<String> {
        let tx = self.undo_stack.pop_back()?;
        for op in tx.ops.iter().rev() {
            match *op {
                AtomicOp::SpawnLine { entity, .. }
                | AtomicOp::SpawnCircle { entity, .. }
                | AtomicOp::SpawnArc { entity, .. }
                | AtomicOp::SpawnPolyline { entity, .. } => {
                    world.despawn(entity).ok();
                }
                AtomicOp::DespawnLine { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::DespawnCircle { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::DespawnArc { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::DespawnPolyline { ref entity, ref data } => {
                    let new_entity = world.spawn((data.clone(), Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::SetLineData { ref entity, ref old, .. } => {
                    world.insert_one(*entity, *old).ok();
                }
                AtomicOp::SetCircleData { ref entity, ref old, .. } => {
                    world.insert_one(*entity, *old).ok();
                }
                AtomicOp::SetArcData { ref entity, ref old, .. } => {
                    world.insert_one(*entity, *old).ok();
                }
                AtomicOp::SetPolylineData { ref entity, ref old, .. } => {
                    world.insert_one(*entity, old.clone()).ok();
                }
                AtomicOp::SetPosition { ref entity, ref old, .. } => {
                    world.insert_one(*entity, *old).ok();
                }
            }
        }
        let label = tx.label.clone();
        self.redo_stack.push_back(tx);
        Some(label)
    }

    pub fn redo(&mut self, world: &mut World) -> Option<String> {
        let tx = self.redo_stack.pop_back()?;
        for op in &tx.ops {
            match *op {
                AtomicOp::SpawnLine { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::SpawnCircle { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::SpawnArc { ref entity, ref data } => {
                    let new_entity = world.spawn((*data, Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::SpawnPolyline { ref entity, ref data } => {
                    let new_entity = world.spawn((data.clone(), Renderable));
                    self.entity_map.record_spawn(*entity, new_entity);
                }
                AtomicOp::DespawnLine { ref entity, .. }
                | AtomicOp::DespawnCircle { ref entity, .. }
                | AtomicOp::DespawnArc { ref entity, .. }
                | AtomicOp::DespawnPolyline { ref entity, .. } => {
                    world.despawn(*entity).ok();
                }
                AtomicOp::SetLineData { ref entity, ref new, .. } => {
                    world.insert_one(*entity, *new).ok();
                }
                AtomicOp::SetCircleData { ref entity, ref new, .. } => {
                    world.insert_one(*entity, *new).ok();
                }
                AtomicOp::SetArcData { ref entity, ref new, .. } => {
                    world.insert_one(*entity, *new).ok();
                }
                AtomicOp::SetPolylineData { ref entity, ref new, .. } => {
                    world.insert_one(*entity, new.clone()).ok();
                }
                AtomicOp::SetPosition { ref entity, ref new, .. } => {
                    world.insert_one(*entity, *new).ok();
                }
            }
        }
        let label = tx.label.clone();
        self.undo_stack.push_back(tx);
        Some(label)
    }

    /// Consume the accumulated entity mapping after an undo/redo cycle.
    /// The caller must apply it to SelectionManager and SpatialIndex.
    pub fn take_entity_mapping(&mut self) -> EntityMapping {
        std::mem::replace(&mut self.entity_map, EntityMapping::new())
    }
}
```

### 8.2 Entity ID Remapping

After any undo/redo operation that respawns entities (De spawn → Spawn on undo, or Spawn → Despawn on redo), the caller must apply the entity mapping to fix up stale handles:

```rust
// Called in ForgeApp after undo/redo:
pub fn apply_entity_remapping(selection: &mut SelectionManager, spatial: &mut SpatialIndex, mapping: &EntityMapping) {
    // Remap selection set
    let mut remapped = HashSet::new();
    for &entity in &selection.selected {
        remapped.insert(mapping.map(entity));
    }
    selection.selected = remapped;
    if let Some(primary) = selection.primary {
        selection.primary = Some(mapping.map(primary));
    }

    // Rebuild spatial index with remapped entities
    // (lazy rebuild: mark dirty, rebuild on next query)
    spatial.dirty = true;
}
```

**Note:** The renderer should never cache entity handles across frames — it reads from the ECS each frame. The `EntityMapping` is consumed after each undo/redo cycle. For large drawings (>10,000 entities), consider incremental spatial index updates instead of full rebuild (deferred to v0.3.0).

pub struct MoveCommand {
    base_point: Option<Point2D>,
    displacement: Option<Point2D>,
    selected_entities: Vec<hecs::Entity>, // Captured from SelectionManager at command start
}

impl Command for MoveCommand {
    fn name(&self) -> &'static str { "MOVE" }

    fn prompt(&self) -> String {
        if self.base_point.is_none() {
            "Specify base point or displacement:".to_string()
        } else {
            "Specify second point or <use first point as displacement>:".to_string()
        }
    }

    fn on_input(&mut self, input: CommandInput, world: &mut World) -> CommandResult {
        match input {
            CommandInput::Point(p) => {
                if self.base_point.is_none() {
                    self.base_point = Some(p);
                    CommandResult::Continue
                } else {
                    let base = self.base_point.unwrap();
                    let dx = p.x - base.x;
                    let dy = p.y - base.y;

                    // Build transaction: SetComponent ops for Position
                    // Apply to all selected entities
                    for &entity in &self.selected_entities {
                        if let Ok(pos) = world.query_one::<&mut Position>(entity) {
                            pos.0.x += dx;
                            pos.0.y += dy;
                        }
                    }
                    CommandResult::Complete
                }
            }
            _ => CommandResult::Error("Specify a point.".to_string()),
        }
    }
}

## 10. Rendering Updates

### 10.1 Selection Highlight

Selected entities are rendered with:
- **Thicker line width:** `width * 1.5`
- **Tint color:** Mixed with `rgba(0, 150, 255, 1.0)` (selection blue)
- **Bounding box:** Dashed rectangle around selection set

Since `EntityRenderer` batches all entities of the same type into a single draw call, per-entity selection state cannot come from a uniform. Instead, use **per-instance vertex attributes** with an `is_selected` field:

```rust
#[repr(C)]
#[derive(Copy, Clone, bytemuck::Pod, bytemuck::Zeroable)]
struct EntityVertex {
    position: [f32; 2],
    color: [f32; 4],
    is_selected: u32,  // 0 or 1 — instance data
}
```

The entity WGSL shader reads the instance attribute and applies tint/width multiplier conditionally:

```wgsl
// src/render/shaders/entity.wgsl (updated)
struct CameraUniform {
    view_proj: mat4x4<f32>,
};
@group(0) @binding(0)
var<uniform> camera: CameraUniform;

struct VertexInput {
    @location(0) position: vec2<f32>,
    @location(1) color: vec4<f32>,
    @location(2) is_selected: u32,
};

struct VertexOutput {
    @builtin(position) clip_position: vec4<f32>,
    @location(0) color: vec4<f32>,
    @location(1) @interpolate(flat) is_selected: u32,
};

@vertex
fn vs_main(in: VertexInput) -> VertexOutput {
    var out: VertexOutput;
    out.clip_position = camera.view_proj * vec4<f32>(in.position, 0.0, 1.0);
    out.color = in.color;
    out.is_selected = in.is_selected;
    return out;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    var color = in.color;
    if in.is_selected == 1u {
        color = mix(color, vec4<f32>(0.0, 0.588, 1.0, 1.0), 0.3);
    }
    color.a = 1.0;
    return color;
}
```

### 10.2 Picking Pass

The picking pass renders to a `Rgba32Uint` texture with the same dimensions as the screen. It is executed **only when needed** (on mouse click, not every frame) to save GPU time. The readback is asynchronous using a two-phase approach to avoid GPU-CPU sync stalls:

1. **Frame N (request):** Submit picking render + copy to staging buffer
2. **Frame N+1 (resolve):** Read back the previous frame's result

The event loop tracks `needs_picking: bool` on `ForgeApp` or `InputState`. On mouse click, `needs_picking` is set to `true` and `request_pick_at` is called. On the next frame, the picking pass renders, `resolve_pick` reads back the result, and `handle_picking_result(entity)` on `SelectionManager` processes the hit.

```rust
// In ForgeApp fields:
pub needs_picking: bool,

// In ForgeApp event handling (on mouse click):
self.needs_picking = true;
self.render_state.picking_pass.request_pick_at(mouse_screen);

// In ForgeApp::render():
if self.needs_picking {
    self.render_state.picking_pass.render(&mut encoder, &self.world, &camera_uniform);
    self.needs_picking = false;
}

// On the NEXT event cycle (or at start of render):
if let Some(entity) = self.render_state.picking_pass.resolve_pick(&self.device, &self.queue) {
    self.selection_manager.handle_picking_result(&mut self.world, entity);
}
```

`SelectionManager::handle_picking_result` processes the hit: if an entity was found under the cursor, select it (replace mode); if no entity, deselect all.

## 16. Risk Assessment

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| **Entity ID instability on undo** | High | Medium | EntityMapping remaps handles in SelectionManager and SpatialIndex after undo/redo; full generational indices deferred to v0.3.0 |
| **Picking pass readback stalls GPU** | Medium | High | Execute picking asynchronously; use previous-frame data |
| **R-tree rebuild too slow for large drawings** | Medium | Medium | Lazy rebuild; incremental updates deferred to v0.3.0 |
| **Snap candidate explosion (polyline vertices)** | Medium | Medium | Cap candidates per entity type; prioritize by distance |
| **Selection highlight uniform buffer bloat** | Low | Low | Use instance data or push constants instead of per-entity uniforms |
| **OFFSET algorithm complexity** | Medium | Medium | Simplify for v0.2.0: support lines and simple polylines only |
| **History memory unbounded** | Low | Medium | Add configurable max_depth; default 1000 transactions |

### Breaking Changes

None. v0.2.0 is a strict superset (no v0.1.0 APIs are removed). However, some v0.1.0 function signatures are extended with new parameters:

| v0.1.0 Function | Change |
|-----------------|--------|
| `InputMapper::handle_event(&mut self, event, camera)` | Gained `snap_engine: &mut SnapEngine, world: &World, spatial: &SpatialIndex` params |
